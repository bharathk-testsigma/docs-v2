## New features

**Analyzer-Guided Auto-Healing** — The AI Analyzer now performs root cause analysis on a failure before healing it, and updates a locator only when a genuine UI change is detected, rather than healing blind.

**Non-Native Mobile Browsers** — Mobile web test cases can run on browsers such as Chrome or Firefox on Android, not only the device's default browser.

## Fixes

**Test Plan Errors** — Fixed the intermittent "Uh-oh" error raised while changing a test plan.

**Go to Project** — Fixed the Go to Project button loading indefinitely.

**Execution Videos** — Fixed execution videos being unavailable for some runs.
