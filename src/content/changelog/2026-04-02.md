## New features

**Agentic Learning for Mobile** — Atto now learns and refines Android and iOS test cases the way it already did for web, refining generated steps against the live application. Mobile authoring reaches parity with web.

**Atto for Salesforce** — Atto generates Salesforce test cases, creating tests for Flows and Workflows with no prompt needed and taking a prompt for everything else. It reads live Salesforce metadata, so generated tests match the org's real state.

**Terminal System Tray Controls** — Open Terminal, check for updates, change settings, and toggle startup from the tray, with the signed-in account always visible. Proxy and agent settings can be reset from Configure Settings instead of by deleting the Testsigma folder.

## Improvements

**Immediate Update Detection** — Terminal detects a new version in near real time and prompts to update, rather than waiting for a scheduled check up to 30 minutes away. Mandatory updates install on the next launch.

**Build Type Detected Automatically** — Terminal downloads the right build for the machine, arm64 or x64, with no manual selection, and reports which one it is running on the Info screen.

**Launch on Startup** — Terminal can start with the machine.

**Relevant NLP Suggestions Only** — The step field no longer loads the full action list on click; suggestions appear once what you type matches something, which removes the lag when creating a step.

**Auto-Heal for Salesforce Flows** — Auto-heal keeps Salesforce Flow tests working as the underlying flows change.
