## New features

**Playwright Execution Engine** — Web and mobile tests now run on Playwright as the execution engine, executing test steps roughly 60% faster than Selenium.

**Unified Mobile** — Author one test case and run it on both Android and iOS, instead of maintaining a duplicate suite per platform.

## Improvements

**Shared Element Repository for Unified Mobile** — A single element entry stores both the Android and the iOS locator, so the two platforms cannot drift apart.

**Step-Level Platform Control** — Turn an individual step off for one platform without splitting the test case in two.
