## New features

**Confluence as an Atto Context Source** — Connect Confluence alongside Figma, Jira, and the test case library as a source Atto generates from. Requires the Confluence integration to be set up in Settings.

**Pause and Resume in Copilot** — Pause a Copilot run at the current step, act on the application yourself, then resume, without setting a breakpoint first.

## Improvements

**Atto Asks Only When It Needs To** — The "Need Attention" state now triggers only where Atto genuinely needs input, evaluated per session, instead of being raised by default.

**No Redundant Library Reads** — "Read existing test case library" switches itself off after its first use, avoiding repeated clicks and wasted generation calls.

**Generation Timing Is Visible** — Each message reports how long its generation took, so response latency can be measured rather than estimated.

**Auto-Heal Accuracy** — Locator keys that a model invents but the DOM does not contain are now tracked rather than passed through silently, and heal prompts can be updated in production without a deployment.
