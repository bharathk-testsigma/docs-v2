## New features

**API Mock Servers** — Create mock endpoints, define mock rules, and run tests against simulated backend responses, across dry runs, plan execution, and local execution.

## Improvements

**Shift-Left UI Testing** — UI tests can start as soon as the frontend is ready, without waiting for backend APIs to be deployed.

**Wider Scenario Coverage from One Test** — Swapping mock rules lets a single test case validate success paths, error states, timeouts, and edge cases.
