## New features

**Copilot Generator** — Generate, insert, and execute steps inline without leaving Copilot. Steps land where they belong in the flow rather than at the end, so there is nothing to reorder afterwards. Web only at this release.

**Global Debug Toolbar** — A persistent toolbar with Resume and Restart that works on every step, so a paused run can be resumed from anywhere.

## Improvements

**Add and Execute Individually** — Run a single generated step or a block of them without ending the authoring session, keeping the generate, execute, verify, and adjust loop in one place.

**Edit Any Step While Paused** — Change a step that has already executed, then resume without losing progress, which matters most in large test cases.

**Loop Changes Apply Immediately** — A modification inside a loop takes effect on the following iterations with no restart.

**Execution Stability** — Fixes to latency, intermittent failures, and unpredictable execution states.
