## New features

**Accessibility Testing** — Run WCAG compliance checks from inside a Testsigma test case, on web, Android, and iOS, with no third-party tooling.

**Documented Coverage** — Web covers 30 of 86 success criteria across all four WCAG principles; Android and iOS each cover 18 of 56, with platform-specific rule implementations. Each rule traces to the criterion it validates.
