## New features

**Mobile Recorder with Live Devices** — The mobile recorder now streams a live Android emulator or iOS simulator inside Testsigma, so taps, swipes, and text input are captured instantly instead of through a screenshot-and-refresh cycle. Released as a beta.

**Custom Dashboards** — Build a dashboard from 30+ widgets covering execution health, reliability, team productivity, AI contribution, and infrastructure performance, each with a chart type suited to its data. Dashboards are shareable and download as a PDF under 25 MB.

**Read-Only User Role** — View-only access across the product, for stakeholders, auditors, and external teams.

**Test Data Profile Folders** — Organize test data profiles in a folder hierarchy rather than a flat list.

## Improvements

**Inspect While Recording** — Inspect elements, read the source tree, and debug locators inside the recorder session, with network and debug logs inline.

**Edit Steps Inside the Recorder** — Reorder, nest, group, and bulk-edit steps without leaving the recording session.

**iOS Locator Strategy** — iOS recording uses Accessibility ID as its primary locator, falling back to auto-heal where an ID is missing.

**Copilot Executor Pause** — Pause an active run without terminating the session, to inspect application state as it stands.
