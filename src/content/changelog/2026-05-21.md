## New features

**Execute from Anywhere** — Start a run from any step without executing the steps before it, so iterating on step 300 of a 500-step test no longer means re-running the 299-step prefix.

**Auto-Healing Simulation** — A wavy underline marks the element being healed as it happens, making auto-healing observable during a run rather than silent.

## Improvements

**Animated Status Banners** — Sticky banners report the current execution state and update as it changes, so a paused, healed, restarted, or finished run reads at a glance without opening logs.

**Add Step Below** — The control now sits on the step itself rather than behind its three-dot menu, which matters most when inserting several steps during a fix pass.

**Sync-Aware Recording** — Inline recording adds steps in bulk and keeps the execution point in step with the application, so you can record mid-debug and resume without restarting. Recording above or below the execution point raises a re-sync prompt instead of surfacing the drift as a later failure.
