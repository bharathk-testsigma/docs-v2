Desktop elements are captured by one of two recorders. Batch takes every UI element in the window in one pass. Selective takes them one click at a time. Both present the result as a hierarchical tree.

<Prerequisites>

- [Testsigma Terminal](/suite/installation/testsigma-terminal/) is installed, with the **WinTest Automation** folder present in the agent directory.
- The application is open on the machine.

</Prerequisites>

## Capture every element at once

<Steps>

1. **Launch** — In **Create Tests → Elements**, click **Record**. Select **Batch Element Recorder** and click **Launch**.

2. **Pick the app** — In the **Select Application** window, select the running application. Click **Start Recording**. Every element in the window is captured.

3. **Review and save** — Browse the tree, then save.

</Steps>

## Capture elements selectively

<Steps>

1. **Launch** — Same entry, but select **Selective Element Recorder**. Click **Launch**, pick the application, and **Start Recording**.

2. **Capture one** — Click **Record**. Hover the element until it highlights green, then click it.

3. **Verify** — Select the element's name in the recorder and click **Locate Element**. The real control highlights in the application.

4. **Save** — Click **Save Element**. **Expand All** and **Collapse All** manage the tree as it grows.

</Steps>
