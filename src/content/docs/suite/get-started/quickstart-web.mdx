Your first web test takes about ten minutes and no code. You create a project, record a short login flow against a sample site, run it on a cloud machine, and read the result. The recorder captures each interaction as an editable step.

<Prerequisites>

- You have a Testsigma account.
- The Testsigma Recorder extension is installed on Chrome.

</Prerequisites>

## Create a web project

<Steps>

1. **Open the project form** — From the **Dashboard**, go to **Project** and click **New Project**.

2. **Set the application type** — Enter a **Project name**, then select **Web application** from the **Application type** dropdown.

3. **Name the application** — Enter an **Application** name and a **Version**, then click **Create**.

</Steps>

A new project starts with a default feature and scenario, so you can create a test case straight away.

## Create a test case

<Steps>

1. **Open the test case list** — Go to **Create Tests → Test Cases**.

2. **Pick a scenario** — In **Test Case Explorer**, expand a **Feature** and click the **+** icon next to the scenario you want.

3. **Name the test case** — Enter a name in the **Test Case Name** field and click **Create**. The **Test Case Details** page opens.

</Steps>

Name the test case after the behaviour under test, such as _Registered user can sign in_. Names appear in run reports, so specific ones make failures easier to read.

## Record the steps

<Steps>

1. **Start the recorder** — On the **Test Case Details** page, click **Record**. A new browser window opens.

2. **Load the application** — Enter the URL you want to test. For this walkthrough, use `https://simply-travel.testsigma.com/`.

3. **Perform the flow** — Click through the actions you want to capture. The **Testsigma Recorder** panel captures each one as a step.

4. **Finish recording** — Click **Stop**.

</Steps>

{/* SCREENSHOT NEEDED: the Testsigma Recorder floating panel over the sample site, with the element inspector, Pause, and Stop controls visible */}

Each interaction is now an [NLP step](/suite/get-started/introduction/#terminology) on the **Test Case Details** page, ready to edit.

```text title="Recorded steps"
Click on Login / Sign Up
Click on Login
Enter <email> in the Email Address field
Click on Continue
Enter <password> in the Password field
Click on Submit
```

<Aside type="tip">
Press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> to freeze the element inspector before you record a dynamic dropdown. Without it, the dropdown closes as you move the pointer away.
</Aside>

## Run the test

<Steps>

1. **Open the run panel** — Click **Run**. The **Ad-Hoc Run** panel opens.

2. **Choose a test machine** — On the **Testsigma Lab** tab, select an **OS & Version**, a **Browser**, and a **Resolution**.

3. **Start the run** — Click **Run Now**. The run detail page opens as execution begins.

</Steps>

Nothing is installed and no grid is configured. To run against an application that is not on the public internet, see [Testsigma Tunnel](/suite/installation/testsigma-tunnel/).

## Read the result

Steps update as each one finishes. A green tick passed and a red cross failed. Open a failed step for the error message, the screenshot captured at the point of failure, and the element the step acted on.

Click **More details** for the machine the run used and a breakdown by status. Screenshots and logs stay with the run, so you can diagnose a failure without reproducing it locally.
