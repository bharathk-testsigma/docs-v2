The marketplace is where add-ons are published and found. Some come from Testsigma, most from other teams, and installing one adds its actions to your own step suggestions. Nothing needs building unless what you want is not there.

<Prerequisites>

- You can open **Add-ons** from the left navigation bar.

</Prerequisites>

## Open the marketplace

Click the add-ons icon in the navigation bar. The page is organised into categories.

| Category | What it holds |
| --- | --- |
| **Community** | Add-ons published by the community, available to everyone |
| **Featured** | The most popular and top-rated of those |
| **New and Updated Addons** | Recently added or recently changed |
| **Testsigma Addons** | Official add-ons from the Testsigma team |
| **Installed Addons** | What is already installed and active on your account |
| **My Addons** | What you have created, public and private |

## Search, sort, and filter

The search bar sits below the **New Addon** button. Search matches a name or a description.

Sort the list by **Package Name**, **Creation Date**, or **Last Updated Date**. Filter it by **Tag**, **Application Type**, **Ratings**, **Creation Date**, or **Last Updated Date**.

## Read an add-on's details

Clicking an add-on opens its details page, which is worth reading before you install.

| Detail | Why it matters |
| --- | --- |
| **Supported Application Types** | Whether it works for the application you are testing |
| **Supported Actions** | The actions it will add to your step suggestions |
| **Data Generators** | Any data generation it contributes |
| **Addon Rating** and **Number of Installs** | How much other teams trust it |
| **Creator Name** and **Creation Date** | Who wrote it and when |
| **Download Source Code** | Read the code before you run it |

<Aside type="tip">
**Download Source Code** is there for a reason. A community add-on executes your test's Java code path, so read it before installing one into an account that touches production data.
</Aside>

## Install an add-on

<Steps>

1. **Open the marketplace** — Click the **Addons** icon in the left navigation bar.

2. **Find one** — Browse the **Community** tab, or search by name or description.

3. **Install it** — Click **Install**.

4. **Refresh** — Reload the page. The actions appear only after a refresh.

</Steps>

<Aside type="note">
Always refresh after installing. Without it the add-on is installed but its actions do not appear in step suggestions, which reads as a broken install.
</Aside>

## Use an installed add-on

<Steps>

1. **Check what it offers** — Go to **Addons**, switch to the **Installed Addon** tab, and click the add-on. A popup lists its actions.

2. **Start a step** — While authoring a test case, begin typing the action's wording in a test step.

3. **Pick it** — Select the action from the suggestions.

</Steps>

An add-on icon before a step marks it as coming from an add-on rather than the built-in set.
