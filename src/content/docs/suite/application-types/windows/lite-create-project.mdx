Windows (Lite) tests Windows applications built on UWP, WinForms, WPF, and Classic Win32. Point Suite at the app's path, capture elements with the recorder, write NLP steps, and execute on your own machine through the agent.

<Prerequisites>

- [Testsigma Agent](/suite/get-started/installation/testsigma-agent/) is set up on a Windows machine.
- **Developer Mode** is enabled on that machine.
- The application is built on UWP, WinForms, WPF, or Classic Windows.

</Prerequisites>

## Create the project and application

<Steps>

1. **Start a project** — Go to **Project > New Project**.

2. **Type it** — Name it and choose **Windows (Lite)** as the **Application type**.

3. **Add the application** — Enter the application name and version, then click **Create**.

</Steps>

<Aside type="note">
An existing project takes a Windows (Lite) application too, under **Project > Project Settings > Applications > New Application** — with **Allow Multiple Applications** enabled first.
</Aside>

## Build and run a test case

<Steps>

1. **Create it** — In **Create Tests > Test Cases**, click **Create Test Case**.

2. **Write the steps** — Compose NLP steps against the [captured elements](/suite/create-and-manage/elements/#record-elements).

3. **Run it** — Click **Run**, select the **Local Test Machine** in the **Ad-Hoc Run** overlay, adjust **Additional settings**, and click **Run Now**.

</Steps>

Windows (Lite) runs execute locally through the agent only — there are no cloud Windows machines for it.

## FAQs

**The recorder fails to start.**

Enable Developer Mode: **Settings > Privacy & security > For developers > Developer Mode**, confirm with **Yes**. Then re-check the application's `.exe` path — a wrong path fails the same way.
