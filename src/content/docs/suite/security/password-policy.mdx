Password Policy is where administrators set password security for the whole organisation. Idle sessions can expire. Repeated failed logins can lock an account. Passwords can be forced to rotate. Each control enables and configures separately.

<Prerequisites>

- You administer the organisation.

</Prerequisites>

## Configure the policy

<Steps>

1. **Open the policy** — Click the **User Profile** menu in the bottom-left corner. Select **Password Policy** under **Organization Settings**, then click **Configure**.

2. **Pick the controls** — Enable each setting in the **Configure Password Policy** dialog. Give each one a value: **Idle Session Timeout** in minutes. **Max Failed Login Attempts** before lockout. **Password Change Frequency** in days.

3. **Save** — Click **Update**.

</Steps>
