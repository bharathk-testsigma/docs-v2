Windows (Lite) elements are captured live from the running application. The recorder launches the app from its path on a local machine; each click captures an element into the repository.

<Prerequisites>

- The [agent](/suite/installation/testsigma-agent/) is running on the Windows machine and the Chrome extension is installed.
- You know the application's executable path.

</Prerequisites>

## Capture elements

<Steps>

1. **Start the recorder** — Go to **Create Tests → Elements** and click **Record**.

2. **Point at the app** — In the **Record Elements** overlay, select the **Local Test Machine**, enter the **App path**, and click **Record**. Wait for the app to load fully.

3. **Capture** — Click an element in the app. Validate the **Name**, **Screen Name**, **Element Type**, and **Value** in the **Create Element** panel, and click **Create**. Repeat as needed.

4. **Stop** — End the recording; the elements are on the **Elements** page.

</Steps>
