Linear integration pushes bugs from a Testsigma run result into your Linear project. Screenshots, annotations, and team sharing travel with each bug. Connecting takes one API key.

<Prerequisites>

- A **Linear API Key**. See [Linear's API and webhooks docs](https://linear.app/docs/api-and-webhooks) to generate one.

</Prerequisites>

## Connect Linear

<Steps>

1. **Open integrations**: Go to **Settings > Integrations**.

2. **Enable the widget**: Turn on the toggle on the **Linear** widget.

3. **Enter the key**: In the **Linear Details** overlay, enter the **API Key** and click **Save & Enable**.

</Steps>

## Report a bug

<Steps>

1. **Open the result**: Go to **Run Results** and open the **Test Case Result** where you want to add a bug.

2. **Start the report**: Click **Report Bug**.

3. **Pick Linear**: In the **Report** overlay, click the **Linear** icon.

4. **Send it**: Review the details and click **Report Bug**.

</Steps>
