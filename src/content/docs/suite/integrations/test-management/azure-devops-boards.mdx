Azure DevOps Boards integration creates work items in your Azure project from a run result. Bugs, epics, tasks, and stories all flow through. Connecting takes the organisation URL and a personal access token.

<Prerequisites>

- Your **Azure DevOps organisation URL** and a **Personal Access Token**, from **Security → Personal Access Tokens** in Azure. Your Azure admin can help with both.

</Prerequisites>

## Connect

<Steps>

1. **Open integrations** — Go to **Settings → Integrations** and enable **Azure DevOps Boards**.

2. **Enter the details** — **Organization URL** and **Access Key**.

3. **Save** — Click **Save & Enable**.

</Steps>

Then report from any run: open the failing **Test Case Result**, click **Report Bug**, pick the **Azure DevOps** icon, review, and click **Report Bug**. **Link to Issue** attaches an existing ticket instead. Testsigma adds the execution video and step screenshots to the created issue automatically.
