Azure DevOps Boards integration creates work items in your Azure project from Testsigma. Bugs, epics, tasks, and stories flow from run results, and test cases link across both tools.

<Prerequisites>

- Your **Azure DevOps organization URL** and a **Personal Access Token** (**Security > Personal Access Tokens**).

</Prerequisites>

## Connect Azure DevOps

<Steps>

1. **Open integrations**: Go to **Settings > Integrations**.

2. **Enable the widget**: Turn on the toggle on the **Azure DevOps Boards** widget.

3. **Enter the details**: In the **Azure DevOps Boards details** prompt, enter the **Organization URL** and **Access Key**, then click **Save & Enable**.

</Steps>

The organization URL is your Azure domain name. Check with your Azure admin if you need help finding either value.

## Report a work item

<Steps>

1. **Open the result**: Go to **Run Results** and open the **Test Case Result** where you want to add a bug.

2. **Start the report**: Click **Report Bug**.

3. **Pick Azure DevOps**: On the **Report** overlay, click the **Azure DevOps** icon.

4. **Send it**: Review the details and click **Report Bug**.

</Steps>

<Aside type="tip">
To attach an existing Azure DevOps issue instead of creating one, click **Link to Issue**, search for the issue, and click **Link Issue**.
</Aside>

## Link test cases

You can also pair a Testsigma test case with an Azure DevOps test case. Copy the test case ID from Azure DevOps. In Testsigma, go to **Create Tests > Test Cases** and open the test case. In the top right corner of the test case details page, enter the ID in the **Enter Azure DevOps ID** box. The two test cases are now linked.
