ClickUp integration pushes bugs from a Testsigma run result into your ClickUp project. Screenshots, annotations, and team sharing travel with each bug. Connecting takes one API token.

<Prerequisites>

- A ClickUp **API token**. ClickUp's [personal API key guide](https://help.clickup.com/hc/en-us/articles/6303426241687-Getting-Started-with-the-ClickUp-API) covers generating one.

</Prerequisites>

## Connect ClickUp

<Steps>

1. **Open integrations**: Go to **Settings > Integrations**.

2. **Enable the widget**: Turn on the toggle on the **ClickUp** widget.

3. **Enter the token**: In the **ClickUp details** prompt, enter the **Personal Token** and click **Save & Enable**.

</Steps>

## Report a bug

<Steps>

1. **Open the result**: Go to **Run Results** and open the **Test Case Result** where you want to add a bug.

2. **Start the report**: Click **Report Bug**.

3. **Pick ClickUp**: In the **Report** overlay, click the **ClickUp** icon.

4. **Send it**: Review the details and click **Report Bug**.

</Steps>
