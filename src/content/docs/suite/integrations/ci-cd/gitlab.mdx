GitLab runs the [shell script](/suite/integrations/ci-cd/shell-script/) as a pipeline job. Commit the script to the project and reference it from `.gitlab-ci.yml`. Every pipeline run then triggers the test plan and waits on the result before later stages run.

<Prerequisites>

- An API key and the test plan ID are set in the committed script (or injected as CI variables).
- The script (here `gitlabcicd.sh`) is committed to the project.

</Prerequisites>

## Configure the job

In **CI/CD → Jobs**, click **Create CI/CD Configuration file**, or use this job directly:

```yaml title=".gitlab-ci.yml"
stages:
 - build
build-code-job:
 stage: build
 script:
 - echo "Calling Shell Script of testsigma"
 - pwd
 - ls -la
 - chmod a+x gitlabcicd.sh
 - ./gitlabcicd.sh
```

<Aside type="note">
Any bash runner works as-is, Docker included. On a PowerShell runner, adapt the job to the PowerShell variant of the script and use PowerShell 7 or later.
</Aside>
