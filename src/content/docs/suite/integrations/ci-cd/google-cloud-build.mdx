Cloud Build watches a connected repository and runs `cloudbuild.yaml` on changes. One build step calls the [shell script](/suite/integrations/ci-cd/shell-script/), so a push triggers the test plan and the build waits on the result before anything later runs.

<Prerequisites>

- A GitHub repository with the project, a Google Cloud project with billing, and admin on both.
- The script (here `tstrigger.sh`) is committed and executable, keys set.

</Prerequisites>

## Configure Cloud Build

<Steps>

1. **Pick the project** — In the Cloud Console, select or create a project.

2. **Open Cloud Build** — Navigation menu → **View all products → CI/CD → Cloud Build**.

3. **Connect the repository** — Under **Repositories**, click **Connect repository** and authorise the source.

4. **Add the build config** — Commit a `cloudbuild.yaml` that runs the script:

</Steps>

```yaml title="cloudbuild.yaml"
steps:
  - name: 'ubuntu:20.04'
    args:
      - '-c'
      - |
        apt-get update && apt-get install -y curl bash coreutils
        chmod +x tstrigger.sh
        ./tstrigger.sh
    entrypoint: bash
options:
  logging: CLOUD_LOGGING_ONLY
```
