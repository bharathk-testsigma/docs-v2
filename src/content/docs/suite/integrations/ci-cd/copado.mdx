Copado deployments call Testsigma through a **URL Callout** step. Each deployment triggers the test plan, and the step either pauses the pipeline for the result or continues without waiting. That choice decides whether failed tests can block a Salesforce release.

<Prerequisites>

- The test plan and an API key exist.

</Prerequisites>

## Configure the deployment step

<Steps>

1. **Open the app** — From the **App Launcher**, open **Copado Release Manager**, then **Deployment → Steps → Add Step**.

2. **Type it** — Name the step and select **URL Callout**.

3. **Choose the behaviour** — **Perform callout and pause step** blocks the deployment until the tests respond; **Perform callout and continue with deployment** fires and forgets.

4. **Describe the call** — Method **POST**, URL `https://app.testsigma.com/api/v1/execution_results`, headers `Authorization: Bearer <API_KEY>`, `Accept: application/json`, `Content-Type: application/json`, and the JSON body with your `executionId`.

5. **Save** — The test plan now fires with every deployment.

</Steps>
