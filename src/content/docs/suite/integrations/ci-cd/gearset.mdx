Gearset integration triggers a Testsigma test plan on every Gearset deployment. An outgoing webhook on the Gearset CI job calls the test plan's trigger endpoint.

<Prerequisites>

- A test plan, an API key ([Settings > API Keys](/suite/settings/developers/)), and the plan's execution ID.

</Prerequisites>

## Configure the webhook in the CI job

<Steps>

1. **Open the webhook settings**: In the Gearset CI job, go to the **Outgoing webhooks** section.

2. **Enter the URL**: In the **Outgoing webhook url** field, enter the API endpoint from the cURL command shown under **Test Plans > CI/CD Integrations > REST API call to start Test Plan**.

3. **Set the payload type**: In the **Payload** field, select **Custom**.

4. **Set authentication**: In the **Authentication** field, select **Authorization**. In the **Credentials** field, add the API key as `Bearer <API-KEY>`.

5. **Add the header**: Add a header with key `Accept` and value `application/json`. In the **Content-Type** field, select **application/json**.

6. **Enter the payload**: In the **Payload** field, enter the execution ID:

   ```json
   {
   "executionId":"<id>"
   }
   ```

7. **Save the job**: Go to **Notifications** and click **Save CI Job**.

</Steps>

<Aside type="note">
The execution ID is on the same **REST API call to start Test Plan** section as the endpoint URL.
</Aside>
