Backlog integration lets you file a bug in a Backlog project from a run result. The ticket carries the test's evidence: annotations, step screenshots, and the execution video. Setup needs two values from Backlog.

<Prerequisites>

- Your organization's Backlog **Account URL** and a Backlog **API Key**.

</Prerequisites>

## Get the API key

Your **Backlog URL** is the address shown in the browser's address bar after you log in.

<Steps>

1. **Open Personal Settings**: click the profile icon drop-down in the top-right corner of Backlog and select **Personal Settings**.

2. **Open API settings**: in the personal settings menu, click **API**.

3. **Generate the key**: under **API Settings**, enter a unique name in the **Memo** field and click **Submit**. Backlog generates the key from the Memo text, so any text works.

4. **Copy the key**: copy the generated API key. It authenticates Testsigma with Backlog.

</Steps>

## Connect Backlog

<Steps>

1. **Open integrations**: go to **Settings > Integrations**.

2. **Enable Backlog**: turn on the toggle on the **Backlog** widget.

3. **Enter the details**: in the **Backlog details** dialog, enter the **Account URL** and **API Key**, then click **Save & Enable**.

</Steps>

## Report a bug

<Steps>

1. **Open the result**: go to **Run Results** and open the **Test Case Result** where you want to add a bug.

2. **Start the report**: click **Report Bug**.

3. **Pick Backlog**: in the **Report** overlay, click the **Backlog** icon. Only bug reporting tools you have enabled appear here.

4. **File it**: review the details and click **Report Bug**.

</Steps>

<Aside type="tip">
To attach the result to an existing Backlog issue instead, click **Link to Issue**, search for the issue, and click **Link Issue**.
</Aside>

When the bug is created, Testsigma automatically adds test result context to the Backlog issue, including the test execution video and step screenshots.
