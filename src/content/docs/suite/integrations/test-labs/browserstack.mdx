[BrowserStack](https://www.browserstack.com/automate) integration runs Testsigma tests on BrowserStack's cloud devices. Author web, mobile web, and mobile tests as usual, then pick it as the test lab for a run.

<Prerequisites>

- Your BrowserStack **username** and **API key** (**Account Settings > Automate** in BrowserStack).

</Prerequisites>

## Connect your account

<Steps>

1. **Open the integration**: under **Settings > Integrations**, on the **Test Lab** tab, enable **BrowserStack**.

2. **Enter your credentials**: in the **BrowserStack details** dialog, enter the username and API key from BrowserStack, then confirm the key.

3. **Save**: click **Save & Enable**.

</Steps>

To update credentials or remove the lab, click **Manage** on the widget.

## Select BrowserStack in a run

When you create an ad-hoc run or a test plan machine profile, select **BrowserStack** as the **Test Lab** type instead of Testsigma Lab. The run then executes on BrowserStack's cloud devices.
