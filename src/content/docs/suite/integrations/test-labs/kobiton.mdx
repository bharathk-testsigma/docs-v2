Kobiton integration runs your Testsigma tests on Kobiton's cloud devices. Web, mobile web, and mobile tests all qualify. Author in Testsigma as usual, then pick Kobiton as the test lab at run time.

<Prerequisites>

- You have your Kobiton **login email** and the **API key** from **Settings → API Keys** in the Kobiton portal.

</Prerequisites>

## Connect

<Steps>

1. **Open integrations** — Go to **Settings → Integrations**, open the **Test Lab** tab, and enable the **Kobiton** toggle.

2. **Enter the details** — Username and API key, with the key confirmed.

3. **Save** — Click **Save & Enable**.

</Steps>

## Use it in a run

On any ad-hoc run or test plan machine profile, select **Kobiton** as the **Test Lab** instead of Testsigma Lab. **Manage** on the integration widget updates the credentials or removes the lab later.
