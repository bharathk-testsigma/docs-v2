Kobiton integration runs Testsigma tests on Kobiton's cloud devices. Author web, mobile web, and mobile tests as usual, then pick it as the test lab for a run.

<Prerequisites>

- Your Kobiton **login email** (the username) and an **API key** (**Settings > API Keys** in Kobiton).

</Prerequisites>

## Connect your account

<Steps>

1. **Open the integration**: under **Settings > Integrations**, on the **Test Lab** tab, enable **Kobiton**.

2. **Enter your credentials**: in the **Kobiton details** dialog, enter the username and API key from Kobiton, then confirm the key.

3. **Save**: click **Save & Enable**.

</Steps>

To update credentials or remove the lab, click **Manage** on the widget.

## Select Kobiton in a run

When you create an ad-hoc run or a test plan machine profile, select **Kobiton** as the **Test Lab** type instead of Testsigma Lab. The run then executes on Kobiton's cloud devices.
