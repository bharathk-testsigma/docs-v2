Sauce Labs integration runs Testsigma tests on Sauce Labs cloud devices. Author web, mobile web, and mobile tests as usual, then pick it as the test lab for a run.

<Prerequisites>

- Your Sauce Labs **username** and **API key**, from the account dashboard.

</Prerequisites>

## Connect your account

<Steps>

1. **Open the integration**: under **Settings > Integrations**, on the **Test Lab** tab, enable **Sauce Labs**.

2. **Enter your credentials**: in the **Sauce Labs details** dialog, enter the username and API key from Sauce Labs, then confirm the key.

3. **Save**: click **Save & Enable**.

</Steps>

To update credentials or remove the lab, click **Manage** on the widget.

## Select Sauce Labs in a run

When you create an ad-hoc run or a test plan machine profile, select **Sauce Labs** as the **Test Lab** type instead of Testsigma Lab. The run then executes on Sauce Labs cloud devices.
