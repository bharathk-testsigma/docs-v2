TestMU integration runs Testsigma tests on TestMU's cloud devices. Author web, mobile web, and mobile tests as usual, then select TestMU as the test lab when starting a run.

<Prerequisites>

- Your TestMU **username** and **API key**, from the account dashboard.

</Prerequisites>

## Connect your account

<Steps>

1. **Open the integration**: go to **Settings > Integrations**, open the **Test Lab** tab, and enable the **TestMU** toggle.

2. **Enter your credentials**: in the **TestMU details** dialog, enter the username and API key from TestMU, then confirm the key.

3. **Save**: click **Save & Enable**.

</Steps>

To update the credentials or remove the lab later, click **Manage** on the integration widget.

## Select TestMU in a run

When you create an ad-hoc run or a test plan machine profile, select **TestMU** as the **Test Lab** type instead of Testsigma Lab. The run starts on the TestMU platform as soon as you execute it from Testsigma.

## View results in TestMU

TestMU restricts result availability outside its own platform. For granular run details, open the **Automation** dashboard in TestMU: your test details appear at the top.
