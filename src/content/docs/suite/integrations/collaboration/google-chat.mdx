Google Chat integration posts test plan status notifications into a Chat space. Create an incoming webhook on the space, add its URL in Testsigma, then enable notifications per test plan.

<Prerequisites>

- A Google Chat space where you can add webhooks.

</Prerequisites>

## Create the webhook in Google Chat

<Steps>

1. **Open the space**: In [Google Chat](https://chat.google.com/), select the chat space where you want to add the connector.

2. **Open its integrations**: Click the space name and select **Apps & Integrations**.

3. **Add a webhook**: Under **Integrations**, go to **Webhooks** and click **Add Webhook**.

4. **Name it**: In the **Incoming webhooks** dialog, enter a **Webhook Name**. Adding an image or avatar URL is optional.

5. **Save and copy**: Click **Save**, then click **Copy link** to copy the generated webhook URL.

</Steps>

## Connect Google Chat to Testsigma

<Steps>

1. **Open integrations**: Navigate to **Settings > Integrations**.

2. **Enable the integration**: Turn on the **Google Chat** toggle.

3. **Enter the details**: In the **Google Chat details** dialog, enter a **Name** and the **Connector URL** you copied, then click **Save & Enable**.

</Steps>

## Enable notifications in a test plan

Once the integration is connected, notifications are configured per [test plan](/suite/run-tests/test-plan/). You can enable them while creating a new test plan or editing an existing one.

<Steps>

1. **Open plan settings**: On the **Create Test Plan** or **Edit Test Plan** page, click the **Test Plan Settings** tab.

2. **Turn on notifications**: Enable the **Send Notification** toggle.

3. **Pick the statuses**: Under **Notify On**, select the statuses you want to be notified about. You can select multiple statuses.

4. **Pick the destination**: Under **Also send messages to**, open the dropdown and select **Google Chat (Google Chat)**.

</Steps>
