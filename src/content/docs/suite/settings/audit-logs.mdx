Audit logs record every key activity in the account, from changes to test assets to sign-ins. Entries are immutable, which is what makes them useful for investigating an incident or answering a compliance question rather than just satisfying curiosity.

<Prerequisites>

- You administer the account.
- You know the per-entity **Activity** logs, which cover one asset's history rather than the account's.

</Prerequisites>

## View audit logs

Go to **Settings → Audit Logs**. The page lists every recorded activity, and each entry carries six fields.

| Field | What it holds |
| --- | --- |
| **Time** | The date and time the action occurred |
| **Event Type** | The entity involved: Test Case, Test Suite, Test Plan, Test Data, Element, Environment, or Authentication & Access Bridge |
| **Project/App/Version** | Where the change was made |
| **Action** | Create, Update, Delete, Login, or Logout |
| **User** | Who performed it |
| **Details** | The fields that changed, with their values |

**Details** is the field that matters in an investigation. It records the specific values, so you can see what a value changed from as well as what it changed to.

## Filter audit logs

Five filters narrow the list, and they combine.

| Filter | What it selects |
| --- | --- |
| **Event Type** | One entity type, such as Test Case or Environment |
| **Action** | One activity type: Create, Update, Delete, Login, or Logout |
| **Date Range** | Activity between a **From Date & Time** and a **To Date & Time** |
| **User** | One person in your organisation |
| **Project** | Actions inside one project |

## Export audit logs

An export runs against whatever filters are applied, so set those first.

<Steps>

1. **Filter the list** — Apply the filters you want on the **Audit Logs** page.

2. **Start the export** — Click **Export** in the top-right corner.

3. **Confirm** — Click **Export** in the dialog. A message confirms it has started.

4. **Collect the file** — Go to **Settings → Exports** and click **Download** beside the generated report.

</Steps>

<Aside type="note">
The export is asynchronous. The entry appears under **Settings → Exports** once the file is generated, so a large date range is worth starting before you need it.
</Aside>
