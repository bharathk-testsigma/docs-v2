Audit logs record every key account activity as immutable entries, from test asset changes to sign-ins. Administrators use them to monitor usage, investigate security incidents, troubleshoot issues, and keep the organization accountable.

<Prerequisites>

- You administer the account.
- You know the per-entity **Activity** logs.

</Prerequisites>

## View audit logs

Go to **Settings > Audit Logs**. The page lists every recorded activity, and each entry carries six fields.

| Field | What it holds |
| --- | --- |
| **Time** | The date and time the action occurred |
| **Event Type** | The entity involved: Test Case, Test Suite, Test Plan, Test Data, Element, Environment, REST API Step, Step Group, or Authentication & Access Bridge |
| **Project/App/Version** | The project, application, and version where the change was made |
| **Action** | Create, Update, Delete, Login, or Logout |
| **User** | Who performed it |
| **Details** | The fields that changed, with their specific values |

**Details** is the field that matters in an investigation. It records specific values, so you can see what a value changed from as well as what it changed to.

## Filter audit logs

Five filters narrow the list, and they combine.

| Filter | What it selects |
| --- | --- |
| **Event Type** | One entity type, such as Test Case or Environment |
| **Action** | One activity type: Create, Update, Delete, Login, or Logout |
| **Date Range** | Activity between a **From Date & Time** and a **To Date & Time** |
| **User** | One person in your organization |
| **Project** | Actions inside one project |

## Export audit logs

An export runs against whatever filters are applied, so set those first.

<Steps>

1. **Filter the list**: apply the filters you want on the **Audit Logs** page.

2. **Start the export**: click **Export** in the top-right corner.

3. **Confirm**: click **Export** in the confirmation dialog. A message confirms the export has been initiated.

4. **Collect the file**: go to **Settings > Exports** and click **Download** next to the generated audit log report.

</Steps>

<Aside type="note">
The export is asynchronous. The entry appears under **Settings > Exports** once the file is generated, so start a large date range before you need it.
</Aside>
