A user's role decides what they can reach, and their project assignments decide where. Both are set in two places: globally under **Settings → Users**, and per project under **Project Settings → Project Members**. You can add as many team members as you need.

<Prerequisites>

- A [project](/suite/settings/projects/) exists to assign people to.
- You hold a role that can invite — **Super Administrator** for the full set.

</Prerequisites>

## The six roles

| Role | What it can do |
| --- | --- |
| **Account Administrator** | Everything a Super Administrator can, plus billing information for the account |
| **Super Administrator** | Complete control over the project, but no access to account or billing information |
| **Test Manager** | Manages multiple projects, including assigning users and adding applications and versions in each |
| **Test Lead** | Manages everything in the assigned project, including its applications and versions |
| **Automation Engineer/Developer** | Writes, views, and updates test cases, plus the test data profiles, elements, and custom functions behind them |
| **Read Only** | Views the project's contents and changes nothing |

<Aside type="note">
Account Administrator and Super Administrator differ on one thing only: billing. If someone needs full control but should not see billing, Super Administrator is the role.
</Aside>

## Invite a user to a project

<Steps>

1. **Open the members list** — Go to **Project → Project Settings** and click **Project Members**.

2. **Start the invitation** — Click **Invite**.

3. **Address it** — In **Invite New Member**, enter the **Email** and select a **Role**.

4. **Send it** — Click **Invite**.

</Steps>

The user gets an invitation email and joins through its link. Once joined, they can work on the project at the role you gave them.

<Aside type="note">
This route offers only **Test Manager**, **Test Lead**, and **Automation Engineer/Developer**. Assigning **Super Administrator** has to be done from **Settings → Users** instead.
</Aside>

## Invite a user and assign projects at once

Use this when someone needs more than one project, or a role the project-level invite does not offer.

<Steps>

1. **Open the users list** — Go to **Settings → Users**.

2. **Start the invitation** — Click **Add new user**.

3. **Fill it in** — Enter the **Email**, tick the projects to assign, and set the role for each.

4. **Send it** — Click **Send Invite**.

</Steps>

## Invite a read-only user

<Steps>

1. **Open the users list** — Go to **Settings → Users**.

2. **Start the invitation** — Click **Add new user** in the top-right corner.

3. **Address it** — Enter the **Email**, then tick **Read Only**.

4. **Send it** — Click **Send Invite**.

</Steps>

`Invite sent successfully` confirms it, and the person appears on **Users** with the status **Invited**.

<Aside type="note">
The status stays **Invited** until they accept. **Resend Invite** beside their name is there for the invitation that went to a spam folder.
</Aside>

## Change a user's role or projects

<Steps>

1. **Find the user** — Go to **Settings → Users**.

2. **Open the menu** — Hover the user and click the kebab menu.

3. **Edit** — Click **Edit User Role**.

4. **Set it** — In **Edit User Role / Assign Projects**, change the roles and projects, then click **Update**.

</Steps>

## Remove a user from a project

A Super Administrator can remove project members.

<Steps>

1. **Open the members list** — Go to **Project → Project Settings** and click **Project Members**.

2. **Pick the user** — Hover them and click **Delete**.

3. **Confirm** — Type `DELETE` in the **Delete Member** dialog and click **Delete**.

</Steps>

You can also remove someone globally from **Settings → Users**.
