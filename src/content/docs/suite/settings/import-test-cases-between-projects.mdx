An import copies test cases from one project into another, along with the step groups, elements, test data profiles, environment variables, and uploads they use. Application types must match: a web test case can only land in a web application.

## Import test cases

<Steps>

1. **Start the import** — In the destination project, go to **Create Tests > Test Cases**, click the ellipsis icon in the **Test Case Explorer**, and click **Import**.

2. **Pick the source** — Under **Select Source**, choose the source **Project**, **Application Name**, and **Version**, then click **Next**.

3. **Choose what comes over** — In **Select Artefacts**, select the test cases. Everything they use — step groups, elements, test data profiles, environment variables, uploads — is selected with them.

4. **Add unlinked assets** — To bring assets no selected test case uses, open that asset's tab and turn on **Show unlinked**. **Show selected** reviews your picks per tab.

5. **Confirm** — Click **Proceed to Import**, review the list under **Start Import**, and click **Confirm**.

6. **Name the save point** — In the **Create a Save Point?** dialog, enter a name and click **Start Importing**. Click **Done** when it finishes.

</Steps>

The review list marks what the import will do to each test case:

| Status | Meaning |
| --- | --- |
| New | Does not exist in the destination — it is created |
| No Change | Exists and is identical — nothing happens |
| Override | Exists but differs — the import replaces it |

The automatic [save point](/suite/web/tests/manage-tests/#snapshot-the-project-with-a-save-point) puts the destination project back as it was if the result is wrong.

<Aside type="note">
Let the import finish — interrupting it can lose data. Import in smaller batches rather than one large one, and note the project keeps at most 10 save points.
</Aside>

## View the import summary

<Steps>

1. **Open the log** — Go to **Settings > Imports**.

2. **Inspect a run** — Click the status of the import you want. The **Import Summary** dialog shows the details of that run; click **OK, Got it** to close.

</Steps>
