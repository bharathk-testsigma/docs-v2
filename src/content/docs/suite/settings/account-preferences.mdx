**Settings > Preferences** holds the switches that apply to the whole account rather than one project. Each is a toggle on its own widget, and each takes effect immediately. This page lists them and covers the two that change who can do what.

<Prerequisites>

- You can reach **Settings > Preferences**, which needs an administrator role.

</Prerequisites>

## What you can toggle

| Preference | What turning it on does |
| --- | --- |
| **Auto Healing** | Lets Suite repair element locators that fail during a run — see [Auto Heal](/suite/web/auto-heal/) |
| **Test Case Review Management** | Adds the submit-and-approve step for test cases |
| **Self-Review Management** | Lets an author review their own test cases |
| **Element Review Management** | Adds the same approval step for elements |
| **Control Who Can Stop Executions** | Restricts the **Stop** button to administrators and to whoever started the run |
| **Disable Onboarding Tutorials** | Stops the getting-started tutorials appearing for signed-in users |

## Control who can stop executions

Turning this on stops one person ending a run someone else is depending on. It is off by default.

<Steps>

1. **Open preferences** — Go to **Settings > Preferences**.

2. **Enable it** — Turn on the **Control Who Can Stop Executions** toggle.

</Steps>

<Aside type="note">
If the toggle is not there, the feature is not enabled for your account. Email `support@testsigma.com` or use the in-app **Chat** and ask for it.
</Aside>

Once on, the **Stop** button in **Usage Details** and **Run Results** follows these rules.

| Role | What they can stop |
| --- | --- |
| **Account Administrator**, **Super Administrator** | Any execution, whoever started it |
| **Test Manager**, **Test Lead**, **Automation Engineer/Developer** | Only the executions and sessions they started themselves |

Everyone can still see every execution. A user who needs to stop a run they did not start has to ask a Super Administrator, who has absolute control.

## Turn off onboarding tutorials

Suite shows tutorials to new users, and they are on for every account by default. They explain how to get started with automation, so leave them on for a growing team.

<Steps>

1. **Open preferences** — Go to **Settings > Preferences**.

2. **Turn them off** — Disable the toggle on **Disable Onboarding Tutorials**.

</Steps>
