Labels tag test cases, elements, step groups, test suites, and test plans, so one filter pulls related work from all five lists. The label list lives in one place — **Settings → Labels** — and every association is visible there.

## Create a label

<Steps>

1. **Open the list** — Go to **Settings → Labels** and click **Add New Label**.

2. **Name it** — Enter a name and click the tick icon. The label joins the list.

</Steps>

Rename or delete a label with the **Edit** and **Delete** icons next to it.

## Attach a label

<Steps>

1. **Open the panel** — Open a test case from **Create Tests → Test Cases** and click **Manage Test Case** in the right rail.

2. **Select labels** — Scroll to **Labels** and pick from the dropdown.

</Steps>

The other asset types attach labels from their own panels:

| Asset | Panel |
| --- | --- |
| Step group | **Manage Step Group** |
| Element | **Update Element** |
| Test suite | **Test Suite Info** |
| Test plan | **Test Plan Details** |

## Trace and clean up labels

<Steps>

1. **Open the label list** — Go to **Settings → Labels** and select a label.

2. **Follow the count** — Click the number next to it. Suite lists every asset the label is attached to, so you can unlink assets or delete the label safely.

</Steps>
