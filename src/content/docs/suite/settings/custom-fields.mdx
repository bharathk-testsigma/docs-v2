Custom fields attach your own attributes to test cases: a sprint, a component owner, a compliance tag. You define the fields once under Settings, fill them in per test case, and filter the test case list by their values.

## Create a custom field

<Steps>

1. **Open the section**: from the left navigation bar, go to **Settings**, then click **Custom Fields** in the **Admin Settings** section.

2. **Start a field**: click **Add new field**. The **Add new field** overlay opens for **Test Case**.

3. **Define it**: enter the **Field Name**, enter the **Description**, and choose the **Field Type** from the dropdown menu.

4. **Save**: configure the type's options and click **Add**.

</Steps>

The **Projects** tab on the same page defines custom fields for the project form instead. See [Projects and applications](/suite/get-started/projects-and-applications/).

## Fill in custom fields on a test case

Custom fields appear on every test case's management panel. [Create test cases](/suite/create-and-manage/create-test-cases/) covers the rest of that panel.

<Steps>

1. **Open the test case**: go to **Create Tests > Test Cases** and select the test case.

2. **Set the values**: click **Manage Test Case** in the utility panel and scroll to the **Custom Fields** section. Enter the values and click **Close**.

</Steps>

## Filter test cases by a custom field

<Steps>

1. **Open the list**: go to **Create Tests > Test Cases** and click **List View** in the **Test Case Explorer** section.

2. **Show the filters**: on the **Test Cases** screen, click **Show Filters**.

3. **Add the filter**: expand **Add Filter** and select the custom field. The list narrows to matching test cases.

</Steps>
