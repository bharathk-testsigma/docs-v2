mdSummary: |
  Testsigma Suite is a low-code test automation platform. You describe a test
  in plain English, and Suite runs it against web, mobile, desktop, Salesforce,
  and API applications without you writing test code. Atto, the AI layer,
  generates test cases from a Jira story, a design, or a prompt; auto-healing
  repairs locators that move; and results feed back into your CI pipeline.

  Where to start:

  - New to Suite: read [Overview](/suite/get-started/overview/), then
    [Concepts](/suite/get-started/concepts/) and
    [Projects and applications](/suite/get-started/projects-and-applications/).
    An application's type and execution engine are fixed once created.
  - Writing tests: [Create test cases](/suite/create-and-manage/create-test-cases/)
    covers the four routes to the same steps — Atto, Copilot, the recorder, and
    NLPs — alongside [step types](/suite/create-and-manage/step-types/),
    [elements](/suite/create-and-manage/elements/), and test data.
  - Running tests: group cases into a [test suite](/suite/run-tests/test-suite/),
    attach it to a [test plan](/suite/run-tests/test-plan/) with a machine
    profile, then read the [run result](/suite/run-tests/results/).
  - Everything else: [Atto AI](/suite/atto/ai-agents/),
    [dashboards and reports](/suite/analytics/dashboards/), and
    [integrations](/suite/integrations/) for CI/CD, trackers, and chat.
