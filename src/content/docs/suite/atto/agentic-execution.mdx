Agentic Learning turns a generated test case into a working one by exploring your application. Where **Run with Copilot** executes the steps you already have, Agentic Learning finds the steps you are missing. See [AI agents](/suite/atto/ai-agents/) for the Generator agent and [Run with Copilot](/suite/atto/ai-agents/#run-with-copilot).

| Question | Agentic Learning | Run with Copilot |
|---|---|---|
| What is it for? | Discovering and correcting the test flow | Executing and validating the generated steps |
| How does it work? | Explores the application to find missing or incorrect steps | Runs the defined steps to check they work |
| What does it focus on? | The accuracy of the test flow | Reliable step execution |
| When does it run? | During generation and learning | After generation, before you save |
| What do you do? | Little. It runs mostly on its own | Debug and validate interactively |
| What do you end up with? | A refined, complete test flow | A test case ready to automate and execute |

Agentic Learning works like an exploratory tester. It learns how the application behaves and adjusts the test case to match the real user journey, rather than assuming the generated steps were correct. It identifies navigation paths, finds and adds missing steps, corrects steps that deviate from the expected workflow, and learns behavior patterns in the application.

Reach for it when the generated flow is incomplete, when steps are missing or out of order, or when the navigation path through the application is unclear.

<Aside type="note">
Agentic Learning needs [Testsigma Terminal](/suite/get-started/installation/testsigma-terminal/) installed, because the learning session drives a real browser on your machine.
</Aside>

## Run a learning session

Turn on **Generator (Live App)** under **Settings > Preferences > Agentic AI > Generator** before you start.

### Start the session

<Steps>

1. Expand a subfolder in the generated test case list and select a test case.

2. Open the **Automated Steps** tab in **Test Case Details**.

3. Hover over **Agentic Learning (Beta)** and select an environment. Atto's Live Editor opens with the manual steps preloaded.

4. Click **Start Learning Live App**. A Chrome browser opens, and the Live Editor executes the manual steps to learn the UI elements.

5. Click **Start Generating Automated Test Case** once the steps have run, and review what was learned.

</Steps>

![Atto's Live editor with the preloaded manual steps and Start Learning Live App](https://s3.amazonaws.com/website-static-docs.testsigma.com/new_images/projects/Updated_Doc_Images/Learning_Live_App_from_Atto.png)

### Control the session

The Live Editor carries these controls while it learns.

- **Reset**: clears every in-progress action and stops the browser learning session
- **Pause** and **Play**: stop the learning temporarily and resume it
- **Stop**: ends the session and closes it
- **Record Manual Steps**: captures steps by hand and adds them to the test case

To record manual steps, click **Record Manual Steps**, perform the actions, and click **Stop Recording**. Select the steps you want under **Manual Recorded Steps**, choose where they go in **Add Step(s) After**, and click **Add Steps**.

![Manual recorded steps in the Live editor, with Add Step(s) After and the session controls](https://s3.amazonaws.com/website-static-docs.testsigma.com/new_images/projects/Updated_Doc_Images/Adding_Manual_Steps_from_Atto.png)

### Finish the session

Click **Run Now** in the Live Editor to execute the test case locally, then click **Accept** to save it to the test case library.

![The Live editor after a local run, with Accept and Reject on the generated test case](https://s3.amazonaws.com/website-static-docs.testsigma.com/new_images/projects/Updated_Doc_Images/Accept_Automated_Case_from_Live_Editor.png)

<Aside type="note">
A session launched through Agentic Learning consumes an Atto session rather than a Copilot parallel.
</Aside>

## The Live Editor

Agentic Learning runs in Atto's Live Editor, which also debugs and modifies a test case while it executes. Testsigma Terminal has to be installed and Copilot ready.

<Steps>

1. Go to **Create Tests > Test Cases** and open or create a test case.

2. Click **Copilot** in the action panel.

3. Select a step from the **Select Step** dropdown in the **Copilot** overlay to set the debug point.

4. Click **Launch**. Copilot executes every step up to that point.

</Steps>

When execution pauses at a debug point or on a failure, the global debug toolbar becomes active, with **Resume**, **Step Over**, **Skip Over**, and **Restart Execution**. See [Copilot](/suite/atto/copilot/#use-the-debug-toolbar) for what each control does.
