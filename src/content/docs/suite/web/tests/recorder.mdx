Recording captures your clicks, typing, and navigation as test steps, and learns the elements behind them. A browser extension does that capture, so install it before **Record** will do anything. This page covers the install, the options, and the controls it adds.

<Prerequisites>

- Chrome, Edge, or Firefox. Recording is not available in other browsers.

</Prerequisites>

## Install the extension

<Tabs syncKey="browser">
<TabItem label="Chrome">

<Steps>

1. **Open the listing** — Go to [Testsigma Recorder](https://chrome.google.com/webstore/detail/testsigma-recorder/epmomlhdjfgdobefcpocockpjihaabdp) on the Chrome Web Store.

2. **Add it** — Click **Add to Chrome**.

3. **Accept the permissions** — Click **Add extension** at the prompt.

</Steps>

A confirmation message appears once it installs.

</TabItem>
<TabItem label="Edge">

<Steps>

1. **Open the listing** — Go to [Testsigma Recorder](https://microsoftedge.microsoft.com/addons/detail/testsigma-recorder/pdgdbfedjpffcnmgedicplikkejikhif) on Edge Add-ons.

2. **Add it** — Click **Get**.

3. **Accept the permissions** — Click **Add Extension** at the prompt.

</Steps>

</TabItem>
<TabItem label="Firefox">

<Steps>

1. **Open the listing** — In Firefox, go to [Testsigma Recorder](https://addons.mozilla.org/en-US/firefox/) on Firefox Add-ons.

2. **Add it** — Click **Add to Firefox**.

3. **Accept the permissions** — Click **Add** at the prompt.

4. **Allow private windows** — Tick **Allow this extension to run in Private Windows** if you need it there.

</Steps>

Firefox needs two more permissions than the others — see [Firefox permissions](#firefox-permissions).

</TabItem>
</Tabs>

## Extension options

Three options control how the recorder behaves. The first two are on by default.

| Option | What it does |
| --- | --- |
| **Enable Inspect Popover on Elements** | Draws a green rectangle around the element under the pointer, so you can see what you are about to capture |
| **Disable Recording Mouse Scroll** | Stops scroll NLPs being added automatically. Keeps test cases clean on a static application with no infinite loading |
| **Enable Developer Mode** | Turns on browser developer mode for element inspection and locator troubleshooting |

<Tabs syncKey="browser">
<TabItem label="Chrome">

Go to **Extensions → Manage Extensions**, click **Details** on the Testsigma widget, then **Extension Options**.

</TabItem>
<TabItem label="Edge">

Open **Extensions**, click the menu on the Testsigma extension, then **Manage Extension**.

</TabItem>
<TabItem label="Firefox">

Go to **Extensions → Extension Settings → Manage Extensions**. On **Testsigma Recorder Extension Details**, click the meatballs icon and select **Preferences**.

</TabItem>
</Tabs>

## Record in a private window

Recording in a private window keeps history and cookies out of the session, which matters when the flow you are recording involves a sign-in you do not want cached.

<Tabs syncKey="browser">
<TabItem label="Chrome">

<Steps>

1. **Open the extension menu** — Right-click the Testsigma extension icon in the toolbar.

2. **Open its settings** — Select **Manage extension**.

3. **Allow it** — Toggle on **Allow in Incognito**.

</Steps>

</TabItem>
<TabItem label="Edge">

<Steps>

1. **Open the extension menu** — Go to **Extensions** and click the meatballs menu on the Testsigma icon.

2. **Open its settings** — Select **Manage Extension**.

3. **Allow it** — Toggle on **Allow in InPrivate**.

</Steps>

</TabItem>
<TabItem label="Firefox">

Tick **Allow this extension to run in Private Windows**, either during installation or later from the extension's details page.

</TabItem>
</Tabs>

## Firefox permissions

Firefox restricts the extension further than Chrome or Edge, and recording fails quietly without these two changes.

### Allow access to site data

<Steps>

1. **Open extensions** — Click the extension icon in the top-right corner, then **Manage extensions**.

2. **Open the details** — On **Testsigma Recorder**, click the menu icon and select **Manage**.

3. **Grant it** — On the **Permission** tab, toggle on **Access your data for all websites**.

</Steps>

### Relax tracking protection

<Steps>

1. **Open settings** — Click the menu icon and select **Settings**.

2. **Choose custom** — Go to **Privacy & Security** and select **Custom** under **Enhanced Tracking Protection**.

3. **Set cookies** — In the custom settings, choose **Cookies from unvisited websites** in the Cookies dropdown.

4. **Apply it** — Click **Reload All Tabs**.

</Steps>

<Aside type="note">
These two settings are what let the recorder reach every site in the browser to capture interactions. Without them the extension loads but records nothing.
</Aside>

## Exclude attributes and classes

Some attributes and classes are not worth building a locator on, because they change with the next deploy. Excluding them up front produces more stable elements than fixing locators later.

<Steps>

1. **Start recording** — Begin a recording session as usual.

2. **Open the menu** — Hover the settings button in the recorder's top-right corner.

3. **Open the list** — Click **Excluded Attributes**.

4. **Add them** — Enter the attributes and classes to skip while recording.

</Steps>

## Freeze an element and act on it

Freezing holds an element still so you can add a verification or another action to it, without replaying the workflow to reach it again.

<Steps>

1. **Create a test case** — Go to **Create Tests → Test Cases**, expand a **Feature**, and click the **+** beside a scenario. Name the case and click **Create**.

2. **Start recording** — On **Test Case Details**, click **Record**, then enter the URL in the new window.

3. **Freeze the element** — Hover it and press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>, or <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> on a Mac.

4. **Open the choices** — Click the **Show More** icon.

5. **Pick one** — Expand the menu and choose a verification or an action. Supply the test data value if prompted.

6. **Finish** — Click **Stop**. You return to **Test Case Details** with the recorded steps.

</Steps>

Verifications check text, attributes, or values. Actions are things like clicking, typing, and selecting.

<Aside type="tip">
Freezing is the answer to a dropdown that closes as soon as you move the pointer away. Freeze it first, then choose the action.
</Aside>
