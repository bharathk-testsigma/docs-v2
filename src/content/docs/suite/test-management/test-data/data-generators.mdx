Every built-in data generator, grouped by function type. Select the function type and the function in the **Data Generators** overlay, then supply the inputs listed here. Click the arrow before **Show Examples** in the overlay to see sample inputs and outputs for the function you selected.

<Aside type="note">
A function whose inputs read None generates its value without any configuration.
</Aside>

Some functions appear twice, once per set of inputs they accept. `randomEmail`, `randomDouble`, `emailAddress`, `safeEmailAddress`, `streetAddress`, `fileName`, `future`, and `past` each have 2 forms.
