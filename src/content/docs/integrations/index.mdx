Testsigma plugs into the tools around it rather than replacing them. Each family below connects at a different point: the pipeline that triggers a run, the tracker that receives a failure, the lab the run executes on, and the channel that hears the result.

![The Integrations page, with a toggle on each integration and the category tabs above](https://s3.amazonaws.com/website-static-docs.testsigma.com/new_images/projects/Updated_Doc_Images/mstinav.png)
