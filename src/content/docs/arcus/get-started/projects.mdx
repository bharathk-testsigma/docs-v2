Projects are the top level of the Arcus hierarchy. Each project holds the test cases, test runs, and test plans for one application. You need at least one project before you can do anything else.

## Create a project

<Steps>

1. **Open project creation** — On the **Dashboard**, click the **Candy Box** icon and select **+ New Project**. The **Create a New Project** dialog opens.

2. **Describe the project** — Enter the **Project Name**, **Description**, and **Project Key**.

3. **Create it** — Click **+ Create Project**.

</Steps>

<Aside type="note">
  Arcus fills in a default **Project Key**, which prefixes the unique ID of
  every test case in the project. You can change it in this dialog, but never
  after the project is created.
</Aside>

## Edit a project

<Steps>

1. **Open settings** — On the **Dashboard**, click the **Candy Box** icon and select **Project Settings**.

2. **Edit the details** — Click **Edit**. The **Edit Project** overlay opens.

3. **Save** — Update the **Project Name** and **Description**, then click **Update Details**.

</Steps>

<Aside type="note">
  **Delete Project** on the same page removes the project permanently after you
  confirm the warning dialog. There is no undo.
</Aside>

## Switch projects

<Steps>

1. **Pick a project** — On the **Dashboard**, click the **Candy Box** icon and select a project from the dropdown.

</Steps>

## Project settings

**Project Settings** opens on its **Overview** section, where the edit and delete actions above live. The other sections each have their own page:

- Import test cases and step groups from a [CSV file](/arcus/imports-and-exports/csv-file/).
- [Export test cases and step groups](/arcus/imports-and-exports/export-tests/) with their details.
- Turn [Review Management](/arcus/test-cases/review-management/) on or off for the project.
