A test plan groups test runs toward one goal — a release, a milestone, a sprint — with its own scope and schedule. [QI Home generates plans automatically](/arcus/qi-home/test-plans/); this page covers the manual kind.

## Before you begin

- You know how to [create test runs](/arcus/test-runs/create-test-runs/) — a plan is a container for them.

## Create a test plan

<Steps>

1. **Start one** — Go to **Test Plans** and select **Create Test Plan**.

2. **Describe it** — Enter a **Title**, an optional **Description**, and optionally a **Start Date** and **End Date**.

3. **Create** — Click **Create Test Plan**.

4. **Fill it** — Click **+ Create Test Run** inside the plan. Or attach an existing run: **Test Runs → open a run → Edit Test Run → Attach Test Plan**.

</Steps>

## Edit a test plan

<Steps>

1. **Edit** — In **Test Plans**, pick **Edit** from the plan's kebab menu, make the changes, and click **Save Test Plan**.

</Steps>

## Delete a test plan

<Steps>

1. **Delete** — Pick **Delete** from the plan's kebab menu, then confirm with **Delete Test Plan**.

</Steps>

## Share a test plan publicly

A public link gives external stakeholders read-only visibility, no account needed.

<Steps>

1. **Open sharing** — Open the plan and click **Share** in the top-right corner.

2. **Enable the link** — Turn on **Anyone with the link can view**, click **Copy**, and share it.

</Steps>

<Aside type="note">
  Viewers can filter the runs and open any run to see its test cases — but they
  cannot change anything.
</Aside>
