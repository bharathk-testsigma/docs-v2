Everything you do to a test case after it exists happens from the **Test Cases** list: editing, reordering, deleting, cloning, bulk updates, comments, and the run history that traces every execution.

## Edit a test case

<Steps>

1. **Open it** — In **Test Cases**, click a case to open the **Quick View** overlay, then click the **Edit** icon. Or pick **Edit** from the case's kebab menu.

2. **Change it** — Update the name, steps, folder, or properties. Changes auto-save.

</Steps>

## Reorder test cases

<Steps>

1. **Open the folder** — Reordering works within one folder at a time.

2. **Drag** — Use the **Drag Handle** on a case. The new position applies immediately and carries into related test runs.

</Steps>

<Aside type="note">
  Reordering is disabled while multiple folders are selected or any filter is
  active.
</Aside>

## Delete a test case

<Steps>

1. **Delete** — Pick **Delete** from the case's kebab menu, then confirm with **Delete Test Case**.

</Steps>

## Bulk actions

<Steps>

1. **Open the Command Center** — In **Test Cases**, press **Command + K** and select **Bulk Update Test Cases**.

2. **Act** — Change properties, move cases to another folder, or delete several at once.

</Steps>

## Clone a test case

Cloning copies every field at clone time. Later edits to the original never touch the copy, and the target can be a different project.

<Steps>

1. **Start the clone** — In the case's folder, click its meatballs menu (⋯) and select **Clone**.

2. **Aim it** — In the **Clone Test Case** dialog, enter a title and pick the **Target Project** and **Folder**.

3. **Clone** — Click **Clone**.

</Steps>

## Comment on a test case

<Steps>

1. **Write** — Open the case and type in the comment field of the **Activity** section. Tag a teammate with **@**.

2. **Post** — Click **Add Comment**.

</Steps>

On any comment you can reply, react with an emoji, or edit and click **Update Comment**. Its meatballs menu offers **Copy Link** and **Delete**.

## View run history

Run history lists every execution of the case across its test runs — status, executor, and timestamp — so you can judge stability without opening each run.

<Steps>

1. **Open the tab** — In the case's **Activity** section, click **Run History**. Click any run for its detailed view.

</Steps>
