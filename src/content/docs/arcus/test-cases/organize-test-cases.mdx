Test cases live in a hierarchical folder tree, with subfolders nesting under parents and cumulative case counts on every folder. Folders give the project its shape; filters and the list view settings decide what you see inside it.

## Create folders

<Steps>

1. **Create the folder** — In **Test Cases**, click **+ Create a Folder** or the **Add Folder** icon. Enter a name and click **+**.

2. **Nest as needed** — Pick **Add Sub Folder** from a folder's kebab menu, name it, and click **+**.

3. **Fill it** — Open the folder and click **+ Create Test Case**.

</Steps>

The kebab menu also offers **Move Folder**, **Rename Folder**, and **Delete Folder**.

<Aside type="note">**Delete Folder** is permanent.</Aside>

## Filter test cases

<Steps>

1. **Open the filters** — In **Test Cases**, click **Filter by**, or press **Command+Shift+F**.

2. **Pick criteria** — Select the filter properties, then click **+** next to each and choose values.

3. **Review** — The list narrows to matches. **Clear All** removes the filters.

</Steps>

The available filters are **Priority**, **Automation Type**, **Test Case Type**, **Status**, **Label**, **Created At**, and **Folder** — the same [properties](/arcus/test-cases/author-test-cases/) a test case carries.

## Customize the list view

<Steps>

1. **Open the menu** — In **Test Cases**, click **View**.

2. **Pick columns** — Select the properties to show or hide. The list updates immediately.

</Steps>
