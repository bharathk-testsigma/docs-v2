Every saved change to a test case becomes a version. The **Version History** overlay lists them all. From there you compare any older version with the current one. You can also restore the case to an earlier state.

## Before you begin

- The test case has been modified at least once.

## View version history

<Steps>

1. **Open the overlay** — Open the test case and click the **History** icon in the top-right corner.

</Steps>

The list shows every saved version with its modification date and the user who made the change.

## Compare and restore

<Steps>

1. **Pick a version** — Hover over it and select **Compare with Current** from its meatballs menu. The **Comparison Mode** page shows the differences.

2. **Restore if needed** — Click **Restore to this Version** to revert the case.

</Steps>

<Aside type="note">
  Comparison always runs against the current version. Two older versions cannot
  be compared. The same meatballs menu also renames a version.
</Aside>
