The ClickUp integration links test defects directly to ClickUp tasks. A defect raised from a test run can attach to existing tasks or create a new one, with QI Home pre-filling the fields.

## Before you begin

- You have an active ClickUp account with the necessary permissions.

## Connect the integration

<Steps>

1. **Start the setup** — Go to **Settings → Integrations** and click **Setup Integration** next to the ClickUp icon. The ClickUp login opens in a new tab.

2. **Authorize** — Log in and click **Authorize** on the **Requesting Access** page.

</Steps>

## Link defects to an existing task

<Steps>

1. **Open the case** — In **Test Runs**, open a run and click the test case. The **Quick View** overlay opens.

2. **Pick the tasks** — Click **Add a Defect**, select **ClickUp** in the top right, and open the **Link to Existing Issue** tab. Choose the tasks.

3. **Save** — Click **Link Tasks**.

</Steps>

<Aside type="note">
  One defect can link to multiple existing tasks. QI Home pre-fills the **Space**,
  **Folder**, **List**, **Task Name**, and **Description** — edit before saving
  if needed.
</Aside>

## Create a new task from a defect

<Steps>

1. **Open the tab** — In the **Add a Defect** overlay, select **ClickUp**, then the **Create a New Issue** tab.

2. **Fill it in** — Pick the **Space**, **Folder**, **List**, **Priority**, **Assignee**, **Task Type**, and **Status**, and enter a **Task Name**.

3. **Create** — Click **Create Task**. ClickUp gets the task and the defect links to it.

</Steps>
