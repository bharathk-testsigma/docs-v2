With the [Jira app installed](/arcus/integrations/jira/set-up/), a Jira issue carries its own test management panel. You create and edit test cases there. You also update run results and raise defects, all without leaving the issue.

## Before you begin

- Your Arcus project is connected to a Jira project.

## View linked tests in an issue

<Steps>

1. **Open the panel** — In the Jira issue, click **Jira App Actions** and select **Test Management by Testsigma**.

</Steps>

**Linked Test Cases** and **Linked Test Runs** show everything tied to the issue. AI-generated and accepted cases join automatically. So do runs containing the issue's cases.

## Create a test case from Jira

<Steps>

1. **Start it** — Under **Linked Test Cases**, click **Create**.

2. **Fill it in** — Enter a **Title**, pick a template and properties, and add **Preconditions**, **Steps**, and **Expected Results**.

3. **Place and save** — Select the folder and click **Create**.

</Steps>

## Link test cases and edit them

<Steps>

1. **Link** — Click **Link** and browse the folders in **Add Test Cases**. Select the cases and click **Add**.

2. **Edit** — Pick **Edit** from a case's meatballs menu (⋯), change the fields, and click **Update**.

</Steps>

<Aside type="note">
  **Link Off** in the same menu unlinks a case from the issue.
</Aside>

## Update run results from Jira

<Steps>

1. **Expand the run** — Under **Linked Test Runs**, expand the test run.

2. **Set the result** — Click the **Status** next to a case and pick the result. The status updates in Arcus too.

</Steps>

## Add or link defects

<Steps>

1. **Open the menu** — Expand the run and click the meatballs menu (⋯) next to the case.

2. **Raise or link** — Click **Add defect**. QI Home pre-fills the issue fields; edit and click **Add**. Or click **Link a defect**, pick the issue under **Bug/Defect**, and click **Link**.

</Steps>
