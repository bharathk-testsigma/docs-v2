With the [extension installed](/arcus/integrations/azure-devops/set-up/), every work item carries a **Test Management by Testsigma** tab. You create and edit test cases there. You also update run results and raise defects, all without leaving Azure DevOps.

## Before you begin

- Your Azure DevOps project is linked to an Arcus project, with the extension installed and authorized.

## View linked tests on a work item

<Steps>

1. **Open the tab** — Go to **Boards → Work items** and open the work item. Click the **Test Management by Testsigma** tab.

</Steps>

**Linked Test Cases** and **Linked Test Runs** show everything tied to the item. AI-generated and accepted cases appear automatically once the project is linked. So do runs containing the item's cases.

## Create a test case from Azure DevOps

<Steps>

1. **Start it** — Under **Linked Test Cases**, click **Create**.

2. **Fill it in** — Enter a **Title**, pick a template and properties, and add **Preconditions**, **Steps**, and **Expected Results**.

3. **Place and save** — Select the folder and click **Create**.

</Steps>

## Link test cases and edit them

<Steps>

1. **Link** — Click **Link**, browse the folders in **Add Test Cases**, select the cases, and click **Add**.

2. **Edit** — Pick **Edit** from a case's meatballs menu (⋯), change the fields, and click **Update**.

</Steps>

<Aside type="note">
  **Link Off** in the same menu unlinks a case from the work item.
</Aside>

## Update run results from Azure DevOps

<Steps>

1. **Expand the run** — Under **Linked Test Runs**, expand the test run.

2. **Set the result** — Click the **Status** next to a case and pick the result. The status updates in Arcus too.

</Steps>

## Add or link defects

<Steps>

1. **Open the menu** — Expand the run and click the meatballs menu (⋯) next to the case.

2. **Raise or link** — Click **Add defect**. QI Home pre-fills the **Work Item Type**, **Title**, and **Description**; edit and click **Add**. Or click **Link a defect** and pick the existing work item.

</Steps>
