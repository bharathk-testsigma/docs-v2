The Linear integration links test defects directly to Linear issues. A defect raised from a test run can attach to existing issues or create a new one, with QI Home pre-filling the fields.

## Before you begin

- You have an active Linear account with the necessary permissions.

## Connect the integration

<Steps>

1. **Start the setup** — Go to **Settings → Integrations** and click **Setup Integration** next to the Linear icon. The Linear login opens in a new tab.

2. **Authorize** — Log in and click **Authorize** on the **Requesting Access** page.

</Steps>

## Link defects to an existing issue

<Steps>

1. **Open the case** — In **Test Runs**, open a run and click the test case. The **Quick View** overlay opens.

2. **Pick the issues** — Click **Add a Defect**, select **Linear** in the top right, and open the **Link to Existing Issue** tab. Choose the issues.

3. **Save** — Click **+ Add Defect**.

</Steps>

<Aside type="note">
  One defect can link to multiple existing issues. QI Home pre-fills the **Team**,
  **Project**, and **Description** — edit before saving if needed.
</Aside>

## Create a new issue from a defect

<Steps>

1. **Open the tab** — In the **Add an Issue** overlay, select **Linear**, then the **Create a New Issue** tab.

2. **Fill it in** — Pick the **Team**, **Project**, **Priority**, **State**, and **Assignee**, and enter an **Issue Title**.

3. **Create** — Click **Create Issue**. Linear gets the issue and the defect links to it.

</Steps>
