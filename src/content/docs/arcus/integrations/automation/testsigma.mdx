Connecting Testsigma to Arcus by Testsigma links an automated test in Testsigma to its manual test case in Arcus. Execution results, logs, and screenshots then flow back into Arcus, so one test case carries both its manual definition and its automated run history.

<Prerequisites>
- An Enterprise plan on both Testsigma and Arcus by Testsigma.
</Prerequisites>

Some tasks can start from either product, and the rest run in one. Each procedure says which.

## Enable the integration

### In Arcus

<Steps>

1. In the left navigation, go to **Settings > Integrations**.

2. Turn on the toggle next to Testsigma.

</Steps>

### In Testsigma

<Steps>

1. In the left navigation, go to **Settings > Integrations**.

2. Turn on the toggle next to Arcus by Testsigma.

</Steps>

## Invite users to both products

With the integration enabled, one invite can add a user to Testsigma, to Arcus, or to both. The invited user receives an email with a link to join the workspace.

### In Arcus

<Steps>

1. On the **Dashboard**, click **Invite Users**. The **Users** section opens under **Settings**.

2. On the **Users** page, click **Invite Users**.

3. In the **Invite User** dialog, enter the email address.

4. Select **Add User in Testsigma** to add the user there as well.

5. Select the projects and assign roles.

6. Click **Send Invite**.

</Steps>

### In Testsigma

<Steps>

1. In the left navigation, go to **Settings > Users**.

2. Click **Add New User**.

3. In the **Add New User** dialog, enter the email address.

4. Select **Add User in Arcus by Testsigma** to add the user there as well.

5. Select the projects and assign roles.

6. Click **Send Invite**.

</Steps>

## Link test cases

You can push a manual [test case](/arcus/create-and-manage/test-cases/) from Arcus to Testsigma as an automated test case, and push an automated test case from Testsigma to Arcus as a manual test case with steps.

### In Arcus

<Steps>

1. In the left navigation, open **Test Cases**, then open the folder and the test case.

2. In the right panel, click **Link a Test Case**. The **Link Testsigma Automated Test Case** dialog opens.

3. Select Testsigma's **Project**, **Application**, and **Version**.

4. Select the test cases to link.

5. Click **Link**.

6. Confirm the result in the **Testsigma Automated Test Case** section of the right panel.

</Steps>

### In Testsigma

<Steps>

1. In the left navigation, go to **Create Tests > Test Cases**.

2. Open the test case, then select **Manage Test Case** from the **Utility Panel**.

3. Click **+ Link New Tests**. The **Link Test Case** dialog opens.

4. Select **Testsigma Test Management** as the **Test Management Tool**.

5. Select a **Test Management Project**.

6. Select the test case to link.

7. Click **Link Test Case**.

8. Confirm the result in Arcus: go to **Test Cases**, open the linked test case, click **Edit Test Case**, and check it under **Testsigma Automated Test Case**.

</Steps>

<Aside type="tip">
To link several at once, turn on the **Link Multiple** toggle and select multiple test cases.
</Aside>

## Automate a manual test case

This starts in Arcus and finishes in Testsigma. Testsigma's Live Editor must be ready before you begin.

<Steps>

1. In the left navigation, open **Test Cases**, then open the folder and the test case.

2. On the test case details overlay, click **Automate with Atto's AI**. The **Select Testsigma Automation Project** dialog opens.

3. Select the Testsigma **Project**, **Application**, and **Version**.

4. Click **Continue**.

</Steps>

Testsigma opens **Atto's Home** for that project, application, and version, with the **Test Case Details** dialog. From there, take 1 of 2 paths.

### Generate the steps first

<Steps>

1. Click **Generate Automated Steps** and wait for the NLP steps to generate. They appear on the **Automated Steps** tab.

2. Click **Agentic Learning** to start learning the live application.

</Steps>

### Start learning directly

<Steps>

1. Click the **Automated Steps** tab.

2. Click the dropdown icon beside **Agentic Learning** and select the **Environment**.

3. Click **Agentic Learning** to start learning the live application.

</Steps>

## Sync a generated test case into Arcus

This starts in Testsigma. It needs AI-generated test cases in **Atto's Home**.

{/* CONFIRM: the ordering. The source has you click Accept and choose a location in the Select Location dialog, and then click the dropdown next to Accept and choose Accept & Sync. Those look like alternative paths rather than sequential steps, so the Select Location step is left out. */}

<Steps>

1. Go to **Atto's Home** and click **Generate with AI** to create a session, or open an existing session.

2. Expand the generated scenario and select a test case.

3. In the test case details dialog, open the **Manual Steps** tab and click **Generate Automated Steps**.

4. Wait for NLP step generation to finish. The steps appear on the **Automated Steps** tab.

5. Click the dropdown arrow next to **Accept**, then select **Accept & Sync with Testsigma TMS**.

6. In the **Sync with Arcus by Testsigma** dialog, select a **Test Management** project and folder.

7. Click **Continue**.

</Steps>

Arcus creates a new test case and links it to the Testsigma test case.

## Link test plans

### In Arcus

<Steps>

1. In the left navigation, open **Test Plans**, then create or open the [test plan](/arcus/run-tests/test-plans/).

2. Under **Testsigma Automated Test Plan**, click **Link a Test Plan**. The **Link Testsigma Automated Test Plan** dialog opens.

3. Select Testsigma's **Project**, **Application**, and **Version**.

4. Select a **Test Plan**.

5. Click **Link**.

6. Confirm the result in Testsigma: open the corresponding plan and check that the Arcus test plan is listed under **Test Management Tool** in the **Test Plan Details** overlay.

</Steps>

### In Testsigma

<Steps>

1. In the left navigation, go to **Test Plans**.

2. Open the test plan, then click **Test Plan Details** from the **Utility Panel**.

3. Click **+ Link New Plans**. The **Link Test Plan** dialog opens.

4. Select **Testsigma Test Management** as the **Test Management Tool**.

5. Select a **Test Management Project**.

6. Select the test plan to link.

7. Click **Link Test Plan**.

8. Confirm the result in Arcus: go to **Test Plans**, open the linked test plan, click **Edit Test Plan**, and check it under **Testsigma Automated Test Plan**.

</Steps>

## Execute a linked test plan

Trigger the plan in Arcus. Testsigma executes it, then Arcus imports the results.

<Steps>

1. In the left navigation, open **Test Plans**, then open a linked test plan.

2. Click the play icon next to the linked **Testsigma Automated Test Plan**.

</Steps>

When execution finishes in Testsigma, Arcus creates a [test run](/arcus/run-tests/test-runs/) for each machine in the plan, holding that machine's test cases and a link to its result page. Every trigger creates a new set of runs.

## View automated results in Arcus

<Steps>

1. In the left navigation, open **Test Plans**, then open the test run inside the test plan. The right panel summarizes the run.

2. Click a test case to open its overlay.

3. Scroll to the **Activity** section for the execution detail, including a link to the Testsigma results page.

</Steps>
