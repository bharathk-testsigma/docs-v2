Connecting Linear to Arcus by Testsigma lets you attach a defect on a test case to a Linear issue, either one that already exists or one you create from Arcus.

<Prerequisites>
- An active Linear account with the necessary permissions.
</Prerequisites>

## Connect Linear

<Steps>

1. In the left navigation, go to **Settings > Integrations**.
2. Click **Setup Integration** next to Linear. The **Linear Login** page opens in a new tab.
3. Log in with your Linear credentials.
4. On the **Requesting Access** page, click **Authorize**.

</Steps>

## Log a defect

<Steps>

1. In the left navigation, open **Test Runs**, then open a [test run](/arcus/run-tests/test-runs/).
2. Click the test case you want to log a defect against. The **Quick View** overlay opens.
3. Click **Add a Defect**.
4. On the **Add an Issue** overlay, select **Linear** in the top right.

</Steps>

From here, either link the defect to an issue that already exists or create a new one.

### Link to an existing issue

<Steps>

1. Select the **Link to Existing Issue** tab.
2. Choose the Linear issues to link.
3. Click **+ Add Defect**.

</Steps>

You can link one defect to several existing issues.

### Create a new issue

<Steps>

1. Select the **Create a New Issue** tab. Arcus prefills **Team**, **Project**, and **Description**.
2. Confirm or change the **Team** and **Project**.
3. Select the **Priority**, **State**, and **Assignee**.
4. Enter an **Issue Title**. A description is optional.
5. Click **Create Issue**. The issue is created in Linear with the defect linked to it.

</Steps>
