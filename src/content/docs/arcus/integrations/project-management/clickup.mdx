Connecting ClickUp to Arcus by Testsigma lets you attach a defect on a test case to a ClickUp task, either one that already exists or one you create from Arcus.

<Prerequisites>
- An active ClickUp account with the necessary permissions.
</Prerequisites>

## Connect ClickUp

<Steps>

1. In the left navigation, go to **Settings > Integrations**.
2. Click **Setup Integration** next to ClickUp. The **ClickUp Login** page opens in a new tab.
3. Log in with your ClickUp credentials.
4. On the **Requesting Access** page, click **Authorize**.

</Steps>

## Log a defect

<Steps>

1. In the left navigation, open **Test Runs**, then open a [test run](/arcus/run-tests/test-runs/).
2. Click the test case you want to log a defect against. The **Quick View** overlay opens.
3. Click **Add a Defect**.
4. On the **Add a Defect** overlay, select **ClickUp** in the top right.

</Steps>

From here, either link the defect to a task that already exists or create a new one.

### Link to an existing task

<Steps>

1. Select the **Link to Existing Issue** tab.
2. Choose the ClickUp tasks to link.
3. Click **Link Tasks**.

</Steps>

You can link one defect to several existing tasks.

### Create a new task

<Steps>

1. Select the **Create a New Issue** tab. Arcus prefills **Space**, **Folder**, **List**, **Task Name**, and **Description**.
2. Confirm or change the **Space**, **Folder**, and **List**.
3. Select the **Priority**, **Assignee**, **Task Type**, and **Status**.
4. Confirm or change the **Task Name**. A description is optional.
5. Click **Create Task**. The task is created in ClickUp with the defect linked to it.

</Steps>
