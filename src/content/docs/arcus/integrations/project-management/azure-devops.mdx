Connecting Azure DevOps to Arcus by Testsigma lets you attach a defect on a test case to an Azure DevOps work item, either one that already exists or one you create from Arcus.

<Prerequisites>
- An active Azure DevOps account with permission to access projects and create work items.
</Prerequisites>

This page covers defect linking. To upload test results from an Azure DevOps pipeline into a test run, see [Azure DevOps](/arcus/integrations/ci-cd/azure-devops/) under CI/CD.

## Connect Azure DevOps

<Steps>

1. In the left navigation, go to **Settings > Integrations**.
2. Click **Setup Integration** next to **Azure DevOps**. The status shows **Connected** once the integration succeeds.

</Steps>

## Log a defect

<Steps>

1. In the left navigation, open **Test Runs**, then open a [test run](/arcus/run-tests/test-runs/).
2. Click the test case you want to log a defect against. The **Quick View** overlay opens.
3. Click **Add a Defect**.

</Steps>

From here, either link the defect to a work item that already exists or create a new one.

### Link to an existing work item

<Steps>

1. On the **Add a Defect** overlay, select the **Link to Existing Work Item** tab.
2. Choose the Azure DevOps work items to link.
3. Click **+ Add Defect**.

</Steps>

You can link one defect to several existing work items.

### Create a new work item

{/* CONFIRM: the overlay name. The source calls it "Add a Defect" in the linking flow and "Add a Work Item - Azure DevOps" here. */}

<Steps>

1. On the **Add a Work Item - Azure DevOps** overlay, select **Create a New Issue**. Arcus prefills **Project**, **Work Item Type**, **Title**, and **Description**.
2. Confirm or change the **Project**, **Work Item Type**, **Title**, and **Description**.
3. Complete the remaining fields: **Tags**, **Assignee**, **Area Path**, **Priority**, and **Iteration Path**.
4. Click **Create Work Item**.

</Steps>
