Jira and Arcus by Testsigma connect in both directions. From Arcus, you attach a defect on a test case to a Jira issue. From Jira, the **Arcus by Testsigma** app lets you create, link, and run test cases against an issue without leaving Jira.

This page covers both. Connecting Jira and logging defects happen in Arcus. Everything from **Install the app in Jira** onwards happens in Jira.

<Prerequisites>
- An active Jira account with the necessary permissions.
</Prerequisites>

## Connect Jira

<Steps>

1. In the left navigation, go to **Settings > Integrations**.

2. Click **Setup Integration** next to Jira. The **Atlassian Login** page opens in a new tab.

3. Log in with your Atlassian credentials.

4. On the **Requesting Access** page, select your app from the **Use app on** dropdown.

5. Click **Accept**.

</Steps>

## Log a defect

<Steps>

1. In the left navigation, open **Test Runs**, then open a [test run](/arcus/run-tests/test-runs/).

2. Click the test case you want to log a defect against. The **Quick View** overlay opens.

3. Click **Add a Defect**.

</Steps>

From here, either link the defect to an issue that already exists or create a new one.

### Link to an existing issue

<Steps>

1. On the **Add a Defect** overlay, select the **Link to Existing Issue** tab.

2. Choose the Jira issues to link.

3. Click **+ Add Defect**.

</Steps>

You can link one defect to several existing issues.

### Create a new issue

<Steps>

1. On the **Add a Defect** overlay, select the **Create a New Issue** tab. Arcus prefills **Project**, **Issue Type**, **Status**, and **Description**.

2. Confirm or change the **Project**, **Issue Type**, and **Status**.

3. Select the **Assignee** and **Reporter**.

4. Enter a **Summary**. A description is optional.

5. Click **+ Add Defect**. The issue is created in Jira with the defect linked to it.

</Steps>

## Install the app in Jira

<Steps>

1. Go to the [Atlassian Marketplace](https://marketplace.atlassian.com/) and search for **Arcus by Testsigma**.

2. Install **Arcus by Testsigma** in your Jira instance.

3. In Jira, go to **Apps > Manage apps** and confirm **Arcus by Testsigma** is listed.

</Steps>

## Connect Testsigma and Jira

<Steps>

1. In Jira, under **Apps** in the left panel, click **Arcus by Testsigma**. The authorization page opens.

2. On the **Connect Testsigma to Jira** page, click **Authorize to Jira Marketplace App Integration**.

3. Click **Continue** in the dialog. You're redirected to the Testsigma sign-in page.

4. Sign in with your Testsigma credentials.

5. Review the logged-in account, then click **Authorize Jira Integration**.

</Steps>

Your Arcus project also has to be connected to a Jira project before test cases and runs appear against an issue.

## Work with test cases in Jira

To see what's already linked, open the Jira issue, click **Jira App Actions**, and select **Arcus by Testsigma**.

<Aside type="note">
Test cases generated and accepted using AI are added to this list automatically.
</Aside>

### Create a test case from Jira

<Steps>

1. In the Jira issue, go to **Arcus by Testsigma > Linked Test Cases**.

2. Click **Create**. The **Create Test Case** dialog opens.

3. Enter a **Title**. A **Description** is optional.

4. Under **Test Case Properties**, select a template type and any other properties.

5. Add **Preconditions**, **Steps**, and **Expected Results**.

6. Select the folder to store the test case in.

7. Click **Create**. The test case appears in the list.

</Steps>

### Link an existing test case

{/* CONFIRM: the tab. The source says Linked Test Runs for this procedure, which looks like an error since it links test cases. */}

<Steps>

1. In the Jira issue, go to **Arcus by Testsigma > Linked Test Cases**.

2. Click **Link**. The **Add Test Cases** dialog opens.

3. Browse the folder structure to find the test cases you want.

4. Select them, then click **Add**.

</Steps>

### Edit or unlink a test case

<Steps>

1. In the Jira issue, go to **Arcus by Testsigma > Linked Test Cases**.

2. Click the ellipsis icon (⋯) next to the test case and select **Edit**.

3. Update the **Name**, **Preconditions**, **Steps**, **Folder**, **Properties**, or any other field.

4. Click **Update**.

</Steps>

<Aside type="tip">
Select **Link Off** from the same menu to unlink the test case from the issue without deleting it.
</Aside>

## Work with test runs in Jira

Test runs containing test cases associated with the issue appear automatically under **Arcus by Testsigma > Linked Test Runs**.

### Update a test case result

<Steps>

1. In the Jira issue, go to **Arcus by Testsigma > Linked Test Runs**.

2. Expand the test run.

3. Click the **Status** next to the test case and choose the result.

4. Refresh the page to see the updated status under **Linked Test Cases**.

</Steps>

<Aside type="note">
The status also updates in Arcus, so you don't have to record it twice.
</Aside>

### Add a defect from Jira

<Steps>

1. In the Jira issue, go to **Arcus by Testsigma > Linked Test Runs**.

2. Expand the test run.

3. Click the ellipsis icon (⋯) next to the test case, then click **Add defect**.

4. In the **Add Defect** dialog, review the **Issue Type**, **Summary**, **Description**, and **Status**, which Arcus fills in for you. Edit any of them.

5. Click **Add**. The defect is created in Jira.

</Steps>

### Link a defect to an existing issue

<Steps>

1. In the Jira issue, go to **Arcus by Testsigma > Linked Test Runs**.

2. Expand the test run.

3. Click the ellipsis icon (⋯) next to the test case, then click **Link a defect**.

4. In the **Link a Defect** dialog, select the issue from the **Bug/Defect** dropdown.

5. Click **Link**.

</Steps>
