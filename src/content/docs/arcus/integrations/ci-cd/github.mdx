A GitHub Actions workflow can push its JUnit results into an Arcus test run on every push. The workflow builds, tests, and uploads the XML report through the Arcus API, reading the token from the `TESTSIGMA_API_TOKEN` repository secret.

## Before you begin

- A project with test runs exists, and you have an [API token](/arcus/settings/api-keys/) stored as the `TESTSIGMA_API_TOKEN` repository secret.
- You have a GitHub account.

## Configure the workflow

<Steps>

1. **Open the workflow file** — In your repository, open or create `.github/workflows/tests.yml`.

2. **Add the workflow** — Paste:

   ```yaml
   name: CI Build and Upload to Testsigma

   on:
   push:
       branches:
       - main  # Or your target branch

   jobs:
   build:
       runs-on: ubuntu-latest

       env:
       TESTSIGMA_API_TOKEN: ${{ secrets.TESTSIGMA_API_TOKEN }}

       steps:
       # Step 1: Check out the code
       - name: Check out code
           uses: actions/checkout@v3

       # Step 2: Build the project and generate test reports
       - name: Build and test with Maven
           run: |
           mvn -B package --file pom.xml

       # Step 3: Upload test results to Testsigma
       - name: Upload test results to Testsigma
           run: |
           echo "Uploading JUnit results to Testsigma..."
           curl --location 'https://test-management.testsigma.com/api/v1/projects/{Project_ID}/junit-import/test-run/{Run_ID}' \
               --header "Authorization: Bearer $TESTSIGMA_API_TOKEN" \
               --form "junit_xml=@target/surefire-reports/TEST-MyTests.xml"
   ```

</Steps>

<Aside type="note">
  Replace `{Project_ID}` with your project ID from the [Arcus
  API](/arcus/api-reference/overview/), and `{Run_ID}` with the ID from the test
  run URL: `.../ui/test_runs/{Run_ID}/`. Point the JUnit path at the XML file
  your build actually generates.
</Aside>

## Trigger a build

<Steps>

1. **Push** — Commit to the configured branch. GitHub Actions runs the workflow, and the Arcus test run updates when it completes.

</Steps>
