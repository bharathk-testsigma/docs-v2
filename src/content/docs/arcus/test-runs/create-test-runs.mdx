A test run is a selection of test cases executed and tracked as one cycle. You choose the cases one of three ways: individually, dynamically through filters, or all at once.

## Before you begin

- A [project](/arcus/get-started/projects/) exists and [test cases](/arcus/test-cases/author-test-cases/) are available.

## Create a test run

<Steps>

1. **Start one** — Go to **Test Runs** and click **Create Test Run**. Enter a **Title** and optional **Description**.

2. **Attach cases** — Click **Add Test Cases** and pick a selection mode in the **Attach Test Cases** dialog.

3. **Finish** — Validate the selection, click **Attach Test Cases**, then **Create Test Run**.

</Steps>

The three selection modes:

| Mode                               | How it selects                                            |
| ---------------------------------- | --------------------------------------------------------- |
| **Select Test Cases Individually** | You tick specific cases; nothing is added automatically   |
| **Adding Cases Using Filters**     | Cases matching your filter criteria are added dynamically |
| **Add All Test Cases**             | Every available case, no selection needed                 |

## Pick cases individually

<Steps>

1. **Choose the mode** — Select **Select Test Cases Individually** and click **Select Test Cases**.

2. **Tick and attach** — Bulk-select the cases and click **Attach Test Cases**, then **Create Test Run**.

</Steps>

## Pick cases with filters

<Steps>

1. **Choose the mode** — Select **Adding Cases Using Filters** and click **Select Test Cases**.

2. **Set criteria** — Pick the filters and their values, then click **Apply Filters**. Matching cases are auto-selected.

3. **Create** — Click **Create Test Run**.

</Steps>

<Aside type="note">
  **Update Filters** on the **Test Run Details** page re-selects the cases
  dynamically whenever you change the criteria.
</Aside>

## Add all cases

<Steps>

1. **Choose the mode** — Select **Add All Test Cases** and click **Select Test Cases**. Every case joins the run.

2. **Create** — Click **Create Test Run**.

</Steps>
