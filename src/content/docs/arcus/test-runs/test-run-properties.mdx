Test run properties are the fields that structure a run and drive its reporting. Each row below is set from the **Test Run Details** page. Set them well and filtering, workload tracking, and reporting stay accurate.

| Property             | What it does                                                                         |
| -------------------- | ------------------------------------------------------------------------------------ |
| **Assign Run**       | **Assign Team Mate** makes one person responsible for the run's progress             |
| **Schedule Run**     | **Start Date** and **End Date** put the run on a timeline                            |
| **Test Environment** | The OS, browser, and device combination the run targets                              |
| **Attach Test Plan** | Links the run to a [test plan](/arcus/test-plans/), so execution tracks the strategy |
| **Labels**           | Tags for categorizing and filtering runs                                             |
