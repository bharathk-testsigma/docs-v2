The Arcus plugin for Claude Code captures your prompts, tool calls, and file changes as you work. When you are done, one command pushes the context to QI Home. QA maps it to a sprint, and QI Home generates test cases from your development activity.

## Before you begin

- Claude Code (latest version) is installed.
- Python 3.9 or later is available as `python3`, and Git is configured.
- You have an active [project](/arcus/get-started/projects/).

## Install the plugin

<Steps>

1. **Add the marketplace and install** — In your terminal, run:

   ```bash
   claude plugin marketplace add testsigmahq/arcus-claude-plugin
   claude plugin install arcus@testsigma
   ```

</Steps>

## Log in and connect your project

<Steps>

1. **Log in** — In Claude Code, run `/arcus:login` and complete the browser flow.

2. **Set the project** — Run `/arcus:project <project-id>`. The ID is in **Arcus → Settings → Project**.

3. **Code** — The plugin captures context in the background from here on.

</Steps>

<Aside type="note">
  Nothing is sent to Arcus until you run `/arcus:push`. Logging in and setting a
  project starts no upload.
</Aside>

## Map and push your context

<Steps>

1. **Map it (optional)** — Run `/arcus:map <ticket-key>`, such as `/arcus:map PROJ-123`, any time before pushing. The context then arrives already routed to that sprint.

2. **Push** — Run `/arcus:push` when you are done.

</Steps>

Unmapped pushes land in **Unmapped Context**, where QA [maps them manually](/arcus/qi-home/context-mapping/map-context/).

## Command reference

| Command                       | What it does                                   |
| ----------------------------- | ---------------------------------------------- |
| `/arcus:help`                 | Lists all Arcus commands                       |
| `/arcus:login`                | Authenticates your Arcus account               |
| `/arcus:logout`               | Logs out                                       |
| `/arcus:project <project-id>` | Connects the plugin to an Arcus project        |
| `/arcus:map <ticket-key>`     | Links the current context to a sprint story    |
| `/arcus:test`                 | Runs tests from QI Home in the current context |
| `/arcus:testsigma-tests`      | Lists existing Testsigma tests for the project |
| `/arcus:push`                 | Uploads the current context to QI Home         |

If you raise a pull request for the same work, QI Home [unifies the PR with this context](/arcus/qi-home/context-mapping/overview/) automatically.
