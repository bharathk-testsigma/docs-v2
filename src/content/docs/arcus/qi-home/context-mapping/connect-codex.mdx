The Arcus plugin for Codex captures your prompts, tool calls, and file changes as you work. One command pushes the context to QI Home, where QA maps it and QI Home generates test cases from it.

## Before you begin

- Codex is installed.
- You have an active [project](/arcus/get-started/projects/).

## Install the plugin

<Aside type="note">
  The install command for the Codex Arcus plugin is pending confirmation from
  the development team. This step is updated before publication.
</Aside>

## Log in, map, and push

The workflow is identical to Claude Code. Run `/arcus:login`, then `/arcus:project <project-id>`. Map with `/arcus:map <ticket-key>` if you want, then `/arcus:push` when done. The full steps and command table live on [Connect Claude Code](/arcus/qi-home/context-mapping/connect-claude-code/).

If you raise a pull request for the same work, QI Home [unifies the PR with this context](/arcus/qi-home/context-mapping/overview/) automatically.
