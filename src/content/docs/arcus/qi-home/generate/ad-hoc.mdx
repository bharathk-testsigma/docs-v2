An Ad-Hoc session generates test cases on demand, without tying them to a sprint. You attach the context yourself, write a prompt, and trigger generation. Use it for new features, releases, or exploratory coverage.

## Before you begin

- You have an active [project](/arcus/get-started/projects/).
- Integrations are connected for any external [context sources](/arcus/qi-home/generate/attach-context-sources/) you plan to use.

## Trigger generation

<Steps>

1. **Go to QI Home** — The **Adhoc** tab opens by default.

2. **Start a session** — Click **Generate with AI**. {/* UNVERIFIED: button label after QI Home removal (was "Generate with QI Home") */} The Playground opens.

3. **Attach context** — Add your sources from the **Add Context** bar. See [Attach context sources](/arcus/qi-home/generate/attach-context-sources/).

4. **Write your prompt** — Describe what to test in the prompt input. See [Effective prompts](/arcus/qi-home/generate/write-prompts/).

5. **Generate** — Click **Generate with AI**. The generation log appears in the left panel.

</Steps>

Generation takes 5–10 minutes, depending on how much context you attached.

<Aside type="note">
  QI Home searches your existing library during generation to avoid duplicating
  coverage. Disable this check in the Playground for faster generation.
</Aside>

## Read the generation summary

When generation completes, the left panel shows what QI Home produced:

- **Test type breakdown** — case counts by type: Functional, Non-Functional, User Experience, and Integration.
- **Scenarios with full test cases** — each scenario, its mapped story, and its case count.
- **Reusable Step Groups proposed** — step groups from your library that apply to the scenarios.
- **Remaining Scenario Outlines** — scenario stubs not yet filled, organized by area.

## Work with the new session

The session appears in the left sidebar with its title, case count, and **In Progress** status. The main area shows three tabs: **Tests**, **Coverage**, and **Test Plan**.

- [Review and accept test cases](/arcus/qi-home/generate/review-and-accept/) from the **Tests** tab.
- Add context or generate more from [the Playground](/arcus/qi-home/use-the-playground/).
- Track [coverage and gaps](/arcus/qi-home/coverage-and-gaps/) from the **Coverage** tab.
