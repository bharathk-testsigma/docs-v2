## Evaluation order

The metrics read left to right in evaluation order. Coverage asks whether enough was tested. Pass Rate asks whether what was tested works. Confidence asks whether the results can be trusted. Release Readiness combines the three, and Release Gate turns the score into a decision.

## Coverage

Coverage measures how much of the generated output you have accepted for testing.

**Formula:** Accepted ÷ (Accepted + Pending) × 100

Pending includes AI-discovered gaps and cases still in **Pending** status. Rejected cases are excluded. Coverage appears as soon as cases are generated, starting at 0%. The bands:

| Band             | Threshold | Meaning                                 |
| ---------------- | --------- | --------------------------------------- |
| **Good**         | ≥ 80%     | Sufficient testing surface approved     |
| **Gap Risk**     | 60% – 79% | Material untested surface               |
| **Critical Gap** | < 60%     | Majority of testing surface unaddressed |

The module-level breakdown lives on [Coverage and gaps](/arcus/qi-home/coverage-and-gaps/).

## Pass Rate

Pass Rate measures how many executed test cases passed.

**Formula:** Passed Units ÷ Executed Units × 100

A unit is one test case on one machine for automated tests, or one test case for manual tests. Each unit counts once sprint-wide, using its latest result. **BLOCKED**, **FAIL**, and **SKIPPED** count as not passed; **NOT RUN** and **IN PROGRESS** are excluded. The metric shows **Awaiting execution** until one unit has run. The bands:

| Band        | Threshold | Meaning                            |
| ----------- | --------- | ---------------------------------- |
| **Healthy** | ≥ 90%     | Production-ready quality           |
| **At Risk** | 75% – 89% | Material failures present          |
| **Blocked** | < 75%     | Build is fundamentally compromised |

## Confidence

Confidence measures how much of your committed scope was validated, and how trustworthy the results are.

**Formula:** Trustworthy Weight ÷ Total Weight × 100

Total Weight sums the priority weights of all units in the topmost _generated_ plan. Trustworthy Weight counts only units that were executed in the topmost _executed_ plan and are not flagged flaky. Priority weights: Critical = 3, High = 2, Medium/Low = 1. It shows **Awaiting execution** until runs exist.

In practice: if QI Home generated Deep Regression but you ran only Smoke, the unrun units stay in the denominator and score zero. Reject the higher plans and keep Smoke, and the scope shrinks — Confidence can then reach 100%. The bands:

| Band       | Threshold | Meaning                                               |
| ---------- | --------- | ----------------------------------------------------- |
| **High**   | ≥ 80%     | Signals are trustworthy; scope mostly fulfilled       |
| **Medium** | 50% – 79% | Reliability or completeness issues; investigate first |
| **Low**    | < 50%     | Pass Rate cannot be relied on                         |

<Aside type="note">
  Confidence depends on the nested plan hierarchy — see [generated test
  plans](/arcus/qi-home/test-plans/) for how the topmost generated and executed
  plans interact.
</Aside>

## Release Readiness

Release Readiness is a 0–100 composite of the three evidence metrics.

**Formula:** (Pass Rate × 0.40) + (Coverage × 0.25) + (Confidence × 0.35)

Pass Rate weighs most because failures are the most direct broken-build signal. Confidence is second as the trust modifier on Pass Rate. Coverage weighs least because gaps are known unknowns. The score is **Awaiting execution** until Pass Rate and Confidence both have values. The bands:

| Band          | Threshold | Meaning                                       |
| ------------- | --------- | --------------------------------------------- |
| **Ready**     | ≥ 80%     | All quality dimensions healthy on average     |
| **High Risk** | 60% – 79% | Release requires explicit risk acknowledgment |
| **Not Ready** | < 60%     | Fundamental issues; do not ship               |

## Release Gate

Release Gate is the final verdict: a rules engine over the metrics with three outcomes.

| State              | Meaning                                                     |
| ------------------ | ----------------------------------------------------------- |
| **GO**             | All thresholds met; safe to release without sign-off        |
| **CONDITIONAL GO** | Soft thresholds breached; release needs QA Lead sign-off    |
| **NO-GO**          | Hard thresholds breached; blocked, no sprint-level override |

The worst state across the five checks wins. The checks and their default thresholds:

| Check                      | GO           | CONDITIONAL        | NO-GO       |
| -------------------------- | ------------ | ------------------ | ----------- |
| **Pass Rate**              | ≥ 95%        | 90% – 95%          | < 90%       |
| **Coverage**               | ≥ 85%        | 70% – 85%          | < 70%       |
| **Confidence**             | High (≥ 80%) | Medium (50% – 79%) | Low (< 50%) |
| **Critical test failures** | 0            | 1                  | > 1         |
| **Critical flaky tests**   | 0            | 1                  | > 1         |

The gate shows **Pending Evaluation** until execution data exists.

<Aside type="note">
  All five checks are configurable per project. A project administrator can
  tighten or loosen any threshold.
</Aside>

## Metric states

How each metric presents across the session lifecycle:

| Metric                | No cases accepted  | Cases accepted, no runs | Runs executed               |
| --------------------- | ------------------ | ----------------------- | --------------------------- |
| **Coverage**          | 0% (all Pending)   | Updates in real time    | Updates in real time        |
| **Pass Rate**         | Awaiting execution | Awaiting execution      | % with band                 |
| **Confidence**        | Awaiting execution | Awaiting execution      | % with band                 |
| **Release Readiness** | Awaiting execution | Awaiting execution      | 0–100 score with band       |
| **Release Gate**      | Pending Evaluation | Pending Evaluation      | GO / CONDITIONAL GO / NO-GO |
