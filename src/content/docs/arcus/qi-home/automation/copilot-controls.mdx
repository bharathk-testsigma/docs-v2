The Copilot panel runs alongside the browser during execution. This page lists every control in the panel, the step tabs and their statuses, and the two debug indicators at the bottom of the browser.

## Panel controls

These sit in the panel header throughout the session:

| Control      | What it does                                   |
| ------------ | ---------------------------------------------- |
| **Pause**    | Pauses at the current step until you resume    |
| **Back**     | Steps back to the previous step                |
| **Forward**  | Steps forward to the next step                 |
| **Settings** | Opens session settings                         |
| **Rec**      | Records the current session state as a step    |
| **Restart**  | Restarts from the first step, once steps exist |
| **Stop**     | Ends the execution session                     |

## Step tabs

The panel shows two views, switchable at any time:

| Tab                 | What it shows                                    |
| ------------------- | ------------------------------------------------ |
| **Manual Steps**    | The original manual steps, for following along   |
| **Automated Steps** | The steps Copilot is executing, with live status |

<Aside type="note">
  Switching tabs only changes the view. It never pauses or stops execution.
</Aside>

## Step statuses

Each entry in **Automated Steps** carries one status:

| Status          | What it means                |
| --------------- | ---------------------------- |
| Green checkmark | Completed successfully       |
| Spinner         | Currently executing          |
| Not started     | Not reached yet              |
| Failed          | Did not complete as expected |

## Debug indicators

Two markers sit at the bottom of the Copilot browser:

| Indicator           | What it does                                                        |
| ------------------- | ------------------------------------------------------------------- |
| **Execution Point** | Marks the step currently running or paused                          |
| **Debug Point**     | A step you chose before launch where execution pauses automatically |

## Add a step mid-run

**Add new step** sits at the bottom of the **Automated Steps** list. Enter the details and the step joins the current session.
