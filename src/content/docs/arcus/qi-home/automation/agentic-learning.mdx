Agentic Learning (Beta) turns a manual test case into an automated one. QI Home opens a browser, walks through each step on your live application, and generates automated steps from what it observed. You write no scripts — you review the output and save it.

## Where the browser runs

**Testsigma Lab** runs the browser in the cloud and needs no local setup. **Local Devices** runs it on your machine through Testsigma Terminal. Go local for apps that are not publicly reachable, local builds, or physical mobile devices.

## Before you begin

- A test case with manual steps is saved in your library.
- For cloud: your application is reachable from a cloud environment.
- For local: **Testsigma Terminal** is installed and running. For mobile, a device or emulator is connected and recognized by Terminal.

## Start from the cloud

<Steps>

1. **Open the dialog** — Open the test case and click **Learn and Automate** at the bottom.

2. **Configure** — Select the **Application** type, then **Testsigma Lab** under **Test Lab**.

3. **Launch** — Click **Launch**. A new tab opens with the Agentic Learning panel.

</Steps>

## Start on local devices

<Tabs>

<TabItem label="Web">

In the **Learn and Automate** dialog, select **Web**, then **Local Devices** under **Test Lab**. Pick the **Environment** and **Browser**, then click **Launch**.

</TabItem>

<TabItem label="Android">

Select **Android**, then **Local Devices**. Pick the **Test Machine**, the connected **Device**, and the app under **App Details** — an **External link**, an app from **Uploaded apps**, or **Add Manually**. Pick the **Environment** and click **Launch**.

</TabItem>

<TabItem label="iOS">

Same dialog as Android: select **iOS**, then **Local Devices**. Pick the **Test Machine**, your connected iPhone, iPad, or simulator, and the .ipa under **App Details**. Pick the **Environment** and click **Launch**.

</TabItem>

</Tabs>

<Aside type="note">
  If Terminal is not running, a prompt appears with a **Launch Terminal** button
  and a download link for your operating system.
</Aside>

QI Home then walks through the steps, marking each with a checkmark. If it gets stuck, it pauses for you — see [learning session controls](/arcus/qi-home/automation/learning-controls/).

## Save to your library

<Steps>

1. **Review the output** — Check the generated automated steps, then click **Save to Library**.

2. **Pick a folder** — Select the folder in the dialog and click **Save**. A success screen shows the steps automated and the time saved.

3. **Return** — Click **Go to Test Case**.

</Steps>

<Aside type="note">
  **Reject** discards the generated steps and the test case stays manual. You
  can run Agentic Learning again any time.
</Aside>

## Verify with Copilot

After learning completes, **Run with Copilot** appears in the panel. It executes the new automated steps in a live browser so you can confirm they work.

<Steps>

1. **Start the run** — Click **Run with Copilot**, then **Continue**. The learning session ends and Copilot opens in a fresh machine.

2. **Watch it execute** — Copilot runs the automated steps in a new tab. The controls are described in [Run with Copilot](/arcus/qi-home/automation/run-with-copilot/).

3. **Save** — When **Test Case Executed Successfully** appears, click **Save Test Case**, pick the folder, and end the session.

</Steps>

<Aside type="note">
  The cloud machine is released when the session ends. Unsaved changes are lost.
</Aside>
