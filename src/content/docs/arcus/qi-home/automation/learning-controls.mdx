An Agentic Learning session mostly runs itself, but you stay in charge. The panel lets you pause, record, and stop; QI Home asks for help when it hits something it cannot do; and a changed application calls for a re-learn.

## Panel controls

The panel sits alongside the browser during a live session:

| Control                     | What it does                                                      |
| --------------------------- | ----------------------------------------------------------------- |
| **Start Learning Live App** | Starts the session when it is ready but not yet running           |
| **Record Step**             | Records the current browser or device state as a step QI Home missed |
| **Pause**                   | Stops QI Home mid-walk until you resume                              |
| **Resume**                  | Continues after a pause                                           |
| **Stop**                    | Ends the session without generating automated steps               |

## Session states

The panel and the test case view reflect where the session is:

| State                       | What you see                                                                                    |
| --------------------------- | ----------------------------------------------------------------------------------------------- |
| **Learning**                | A spinner on the current step and a **Learning...** status                                      |
| **Needs user's input**      | A yellow banner with a **Go to Session** button                                                 |
| **Completed**               | Checkmarks on all steps, plus **Generate Automated Steps**, **Save to Library**, and **Reject** |
| **Generation Failed**       | An error with an **Edit** option                                                                |

On the sprint or session view, the test case itself shows **Agentic Learning in progress**, **Needs user's input**, or **Learn and Automated**. {/* UNVERIFIED: status labels after QI Home removal */}

## Provide input when QI Home is stuck

<Steps>

1. **Open the session** — Click **Go to Session** in the banner on the test case view.

2. **Complete the blocking action** — Do the thing QI Home could not, such as a CAPTCHA or a multi-factor prompt. QI Home resumes the remaining steps automatically.

</Steps>

<Aside type="note">
  Closing the browser tab without completing the action ends the session. You
  would need to start a new one.
</Aside>

## Re-learn a test case

When the application changes, update an automated test case instead of editing steps manually.

<Steps>

1. **Start the re-learn** — On the test case view, click **Re-learn and Automate**. This button replaces **Learn and Automate** once a case is automated.

2. **Configure and launch** — The dialog offers the same options as the first session. Pick the application type, test lab, and environment, then click **Launch**.

3. **Save the new steps** — When the session completes, save to your library. The previous automated steps are replaced.

</Steps>

<Aside type="note">
  The old automated steps survive until you save the new ones. Rejecting the
  re-learn keeps the original automation.
</Aside>
