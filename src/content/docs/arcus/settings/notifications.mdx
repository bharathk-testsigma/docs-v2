Notifications keep the team aligned without checking Arcus: alerts go out over Email, Slack, or Microsoft Teams when key events happen. Every event can be toggled per channel, and each channel's message template is editable.

## Before you begin

- You have an active account in the channel receiving the notifications — a mailbox, a Slack workspace, or a Teams workspace.

## Notification events

The same event list drives every channel; toggle each on or off per channel:

| Event                       | Fires when                         |
| --------------------------- | ---------------------------------- |
| Test Run Assigned           | a run is assigned to a user        |
| Test Case Assigned          | a case is assigned to a user       |
| Test Case Waiting on Review | a case is submitted for review     |
| Test Case Approved          | a case is approved                 |
| Test Case Rework Requested  | a case is sent back for rework     |
| Comments Mentioned          | a user is @-mentioned in a comment |
| Test Run Completed          | a run finishes or changes status   |
| Test Run Added to Test Plan | a run joins a plan                 |
| Test Plan Completed         | a plan finishes                    |
| Test Plan Daily Summary     | daily, for active plans            |

## Customize a channel

<Steps>

1. **Open the channel** — Go to **Settings → Notifications**, expand **Notifications**, and click **Email**, **Slack**, or **MS Teams**.

2. **Edit the template** — Hover over an event and click the **Edit** icon. Email edits **HTML Content**; Slack and Teams edit the **Notification Template**.

3. **Test and save** — Click **Send Test Email** or **Send Test Notification**, then **Save**.

</Steps>

<Aside type="note">
  To send email from your own address, configure
  [SMTP](/arcus/settings/smtp-configuration/) first.
</Aside>

<Aside type="note">
  Authorize the Teams integration with a separate Microsoft account used only
  for setup. A Microsoft Teams limitation means the authorizing account receives
  no notifications.
</Aside>

## Notify from a test plan

<Steps>

1. **Open the plan** — In **Test Plans**, create or open a plan and find its **Notifications** section.

2. **Add destinations** — Enter email addresses separated by commas, or pick the **Slack** channel from the dropdown. Alerts fire when the plan is created or updated.

</Steps>
