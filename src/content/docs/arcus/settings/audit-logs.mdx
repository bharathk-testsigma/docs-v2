**An audit log** is an immutable record of a change made in your Arcus by Testsigma account. Together they cover every user action, including changes to test assets and account access events. Administrators use them to monitor account usage, investigate security incidents, and establish accountability.

## View audit logs

In the left navigation, go to **Settings > Audit Logs**. The page lists all recorded activity.

Each entry shows:

- **Time**: the date and time the action occurred.
- **Event Type**: the type of entity that changed.
- **Action**: the type of action performed.
- **Project**: the project the change was made in.
- **User**: the user who performed the action.
- **Details**: the fields that changed, with their values.

## Filter audit logs

Five filters narrow the list:

- **Event Type**: logs for one type of entity.
- **Action**: logs for one type of activity.
- **Date Range**: activity within a time frame you choose.
- **User**: activity by one user in your organization.
- **Project**: activity within one project.
