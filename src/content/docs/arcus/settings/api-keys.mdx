API keys authorize calls to the [Arcus API](/arcus/api-reference/overview/). With one, your tooling can create projects, test cases, test runs, and test plans, or trigger executions. Each key has a name, so you can tell integrations apart.

## Generate a key

<Steps>

1. **Open the section** — Go to **Settings → API Keys** and click **Generate New Key**.

2. **Name and create** — Enter a **Key Name** and click **Generate**.

3. **Copy it** — Copy the key. It is your authorization credential.

</Steps>
