**A label** categorizes test cases and test runs so you can filter and track them. Teams typically label by functionality, for example Smoke Test, Regression, or API Testing.

## Manage labels

Adding, editing, and deleting all start the same way.

<Steps>

1. In the left navigation, go to **Settings > Manage Labels**.

2. Click **Edit**.

</Steps>

Then follow the path you need.

### Add a label

<Steps>

1. Click **Add Labels**.

2. Enter a **Name**.

3. Click the check icon to save.

</Steps>

### Edit a label

<Steps>

1. Select the label to update.

2. Update the **Name**.

3. Click **Update Details**.

</Steps>

### Delete a label

<Steps>

1. Click the delete icon next to the label.

2. Confirm in the **Delete \<Label_Name\>** dialog.

</Steps>
