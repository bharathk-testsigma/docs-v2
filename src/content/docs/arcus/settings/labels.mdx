Labels tag test cases and test runs by theme — Smoke Test, Regression, API Testing — so filters can pull them together. The **Manage Labels** section owns the label list; all three actions below start from its **Edit** button.

## Add a label

<Steps>

1. **Open the editor** — Go to **Manage Labels** and click **Edit**.

2. **Add** — Click **Add Labels**, enter a **Name**, and click **✔**.

</Steps>

## Rename a label

<Steps>

1. **Open the editor** — Go to **Manage Labels** and click **Edit**.

2. **Rename** — Select the label, update the **Name**, and click **Update Details**.

</Steps>

## Delete a label

<Steps>

1. **Open the editor** — Go to **Manage Labels** and click **Edit**.

2. **Delete** — Click the **Delete** icon next to the label and confirm in the dialog.

</Steps>
