Custom fields carry project-specific information the default [properties](/arcus/test-cases/author-test-cases/) do not cover. Once created, a field appears on test cases. It also joins the bulk-edit actions and works as a filter, so your own attributes behave like built-in ones.

## Create a custom field

<Steps>

1. **Open the section** — Go to **Settings → Custom Fields** and click **+ Add New**.

2. **Define it** — Enter the **Field Name** and optional **Description**. Select the **Field Type**, enter its values, and click **Add**.

</Steps>

## Add custom fields to a test case

<Steps>

1. **Set the value** — Open the test case. Select the custom field values in **Test Properties**.

</Steps>

## Bulk-edit custom fields

<Steps>

1. **Select cases** — In **Test Cases**, select the cases to update and press **Command + K**.

2. **Apply the value** — Choose the field and set the value. Click **Update Test Cases**.

</Steps>

## Filter by custom fields

<Steps>

1. **Filter** — In **Test Cases**, click **Filter by**. Select the custom field to filter on.

</Steps>
