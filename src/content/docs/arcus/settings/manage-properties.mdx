The **Manage Properties** section edits the default values behind four test case properties: **Test Case Priority**, **Automation Type**, **Test Case Status**, and **Test Case Type**. New test cases pick from these values.

## Edit a property

<Steps>

1. **Open the editor** — Go to **Settings → Manage Properties** and click **Edit**.

2. **Rename** — Update the property names in the **Edit Properties** overlay and click **Update Details**.

</Steps>

<Aside type="note">
  Values can be renamed, but fields cannot be added or deleted. For new fields,
  use [custom fields](/arcus/settings/custom-fields/).
</Aside>

## The four properties

| Property               | What it captures                                                                    |
| ---------------------- | ----------------------------------------------------------------------------------- |
| **Test Case Priority** | Urgency and execution order                                                         |
| **Automation Type**    | Automated · Not Automated · Automation Not Required · Can't Be Automated · Obsolete |
| **Test Case Status**   | The case's place in the testing lifecycle                                           |
| **Test Case Type**     | Purpose and testing approach                                                        |
