A CSV file moves test cases into Arcus in bulk. This is also the final step when migrating from [Zephyr](/arcus/imports-and-exports/zephyr/), [TestRail](/arcus/imports-and-exports/testrail/), or [BrowserStack](/arcus/imports-and-exports/browserstack/) — each exports a CSV that imports the same way.

## Before you begin

- A [project](/arcus/get-started/projects/) and [folders](/arcus/test-cases/organize-test-cases/) exist.

## Upload the file

<Steps>

1. **Open the importer** — Go to **Import Cases** in the left nav, or click **Import** on the **Dashboard**.

2. **Pick the template** — Click **Import via CSV** and choose **Steps** for step-based cases or **Document** for document-style ones.

3. **Upload** — Click **Upload File** and select the CSV.

</Steps>

## Map and import

<Steps>

1. **Check the preview** — Verify the content in **Uploaded File Preview** and click **Next**.

2. **Review the mapping** — QI Home maps CSV columns to test case fields automatically. Fix any missing or wrong mappings in **Map Properties**, and check **Test Case Preview**.

3. **Import** — Click **Begin Import**. An import log appears in the **Imports** section.

</Steps>

## View import results

Open the log in **Imports** when the run completes. The **Import Results** page summarizes **Total**, **Imported**, **Skipped**, and **Failed** test cases:

- **Failed to Import** lists each failure with its **Error Type and Reason**, such as duplicate titles.
- **Skipped** lists cases ignored, for example ones that already exist in the project.
- **Imported Test Cases** confirms what landed, with details.

Fix the CSV from these findings and re-import if needed.
