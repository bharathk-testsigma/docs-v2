Moving from TestRail takes two steps: export the cases from TestRail as a CSV, then run them through the Arcus CSV importer. TestRail exports CSV directly, so no conversion is needed.

## Export test cases from TestRail

<Steps>

1. **Find the cases** — On the TestRail dashboard, go to **Projects → Test Cases**.

2. **Export** — Select the test cases, click the **Export** icon, and select **Export to CSV**.

3. **Scope the file** — In the **Export to CSV** dialog, pick the **Sections** (folders) and **Columns** (properties) to include. The file downloads as **.csv**.

</Steps>

## Import into Arcus

<Steps>

1. **Open the importer** — On the **Dashboard**, click **Import Test Cases**. Or go to **Test Cases** and click **Import**.

2. **Upload** — Click **Import via CSV**, then **Upload File**, and select the file.

</Steps>

The mapping and results steps are the same as any CSV import — follow [Import test cases from a CSV file](/arcus/imports-and-exports/csv-file/) to map the columns and review the log.
