Moving from BrowserStack Test Management takes two steps: export the cases as a CSV, then run them through the Arcus CSV importer. Only test cases created with the Plain Text template can be imported.

## Export test cases from BrowserStack

<Steps>

1. **Find the cases** — On the BrowserStack Test Management dashboard, go to **Projects → Test Cases**. Select the folder to export.

2. **Export** — Select the test cases, then **Export as CSV** from the **Export** dropdown. The file downloads as **.csv**.

</Steps>

## Import into Arcus

<Steps>

1. **Open the importer** — On the **Dashboard**, click **Import Cases**. Or go to **Test Cases** and click **Import**.

2. **Upload** — Click **Import via CSV**, then **Upload File**, and select the file.

</Steps>

The mapping and results steps are the same as any CSV import — follow [Import test cases from a CSV file](/arcus/imports-and-exports/csv-file/) to map the columns and review the log.
