## Key rules

- **Do not invent terminology.** If a term isn't in the reference, don't make
  one up — flag it as unverified.
- **Echo UI labels exactly.** Button text, menu items, tab names, field labels —
  use the exact wording from the reference, not paraphrases.
- **Distinguish Suite from Arcus.** They are separate products at separate URLs
  with different navigation. Don't conflate them.
- **Atto spans both products.** It's not exclusive to Suite or Arcus — it's
  the AI layer across both.
- **Classic vs Modern matters.** Features like Unified Mobile are Modern-only.
  Don't assume Classic compatibility unless the reference says so.
- **This reference is dated July 2026.** Features marked as Beta, In-Progress,
  or with known limitations may have changed. Flag when relevant.
